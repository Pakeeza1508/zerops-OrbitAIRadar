# Orbit API Contract

All protected endpoints use:

```http
Authorization: Bearer <JWT>
```

## Authentication

### `POST /api/auth/register`

```json
{
  "email": "student@example.com",
  "password": "strong-password",
  "fullName": "Student Name"
}
```

Returns `accessToken` and user.

### `POST /api/auth/login`
Same shape minus `fullName`.

### `GET /api/auth/me`
Current authenticated user.

## Profile

### `GET /api/profile`

### `PUT /api/profile`

```json
{
  "fullName": "Student Name",
  "country": "Pakistan",
  "educationLevel": "undergraduate",
  "fieldOfStudy": "Computer Science",
  "institution": null,
  "graduationYear": 2027,
  "experienceLevel": "beginner",
  "skills": ["Python", "React", "AI"],
  "interests": ["Open Source"],
  "preferredCategories": ["internship", "fellowship", "open_source", "hackathon"],
  "locationPreference": ["remote", "global"],
  "preferredCountries": [],
  "fundingPreference": "funded_only"
}
```

## Opportunities

### `GET /api/opportunities`

Supported query parameters:

- `q`
- `category` comma-separated
- `remote=true|false`
- `funded=true|false`
- `deadlineBefore=<ISO datetime>`
- `deadlineAfter=<ISO datetime>`
- `countries` comma-separated
- `education` comma-separated
- `skills` comma-separated
- `minMatch=0..100`
- `sort=best_match|newest|deadline`
- `page`
- `pageSize`
- `includeUnverified`

Each item contains factual opportunity data plus user-specific:

- `matchScore`
- `eligibilityStatus`
- `matchedSkills`
- `missingSkills`
- `matchingReasons`
- `daysRemaining`
- `applyUrl`

### `GET /api/opportunities/{id}?explainAI=true`
Returns detail; optional Groq explanation when configured.

## Dashboard

### `GET /api/stats`

Returns:

```json
{
  "recommended": 12,
  "closingSoon": 3,
  "newToday": 4,
  "saved": 5,
  "totalActive": 42
}
```

## Saved

### `POST /api/opportunities/{id}/save`
Creates/refreshes an immutable factual snapshot.

### `DELETE /api/opportunities/{id}/save`

### `GET /api/saved`
Returns saved rows; `expired=true` if its deadline passed or the master record was removed.

### `PATCH /api/saved/{saved_id}`

```json
{
  "applicationStatus": "planning",
  "notes": "Prepare proposal this week."
}
```

Status values: `saved`, `planning`, `applied`.

## Search

### `POST /api/search/ai`

```json
{
  "query": "Fully funded remote AI internships for Pakistani undergraduate students"
}
```

Groq converts the request to an allow-listed Pydantic filter structure when configured. Without Groq, a deterministic parser is used.

### `POST /api/search/live`

```json
{
  "query": "open source mentorship applications",
  "maxResults": 12
}
```

Runs discovery, then returns newly available matching records. SearXNG adds broader search candidates only when configured.

## Ingestion

### `POST /api/ingestion/run`

```json
{
  "query": null,
  "maxCandidates": 30
}
```

Returns immediately with a run id and schedules the ingestion in FastAPI background tasks.

### `GET /api/ingestion/runs`
### `GET /api/ingestion/runs/{id}`
### `GET /api/ingestion/sources`
### `POST /api/ingestion/seed-sources`

Run fields include:

- sources attempted/succeeded
- URLs discovered/fetched
- new/updated/duplicate/expired/failed counts
- AI calls
- status and errors

# Orbit Backend — Local Testing Guide

## 1. Prerequisites

Install:

- Python 3.12 (recommended)
- MongoDB locally **or** a MongoDB Atlas connection string

Groq and SearXNG are optional during the first local boot.

## 2. Create environment

From the backend folder:

```bash
python -m venv .venv
```

Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Install:

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
pip install -r requirements-dev.txt
```

## 3. Configure `.env`

Copy `.env.example` to `.env`.

Minimum local configuration:

```env
MONGO_URL=mongodb://localhost:27017
DB_NAME=orbit
JWT_SECRET=replace-with-a-long-random-secret
CORS_ORIGINS=http://localhost:3000
```

### Add Groq later

When ready for live AI tests:

```env
GROQ_API_KEY=YOUR_KEY_HERE
GROQ_MODEL=openai/gpt-oss-20b
```

The key belongs **only in the backend `.env`**, never in React.

### Add SearXNG later

```env
SEARXNG_BASE_URL=http://localhost:8080
```

If omitted, source-registry crawling still works.

## 4. Start backend

```bash
uvicorn server:app --reload --host 0.0.0.0 --port 8000
```

Verify:

```text
GET http://localhost:8000/health
GET http://localhost:8000/ready
GET http://localhost:8000/docs
```

`/ready` should return HTTP 200 only when MongoDB is reachable.

## 5. Core test flow

Use Swagger at `/docs`, Postman, or curl.

1. `POST /api/auth/register`
2. Copy returned `accessToken`
3. Add `Authorization: Bearer <token>`
4. `PUT /api/profile`
5. `POST /api/ingestion/run`
6. Poll `GET /api/ingestion/runs/{id}`
7. `GET /api/opportunities?sort=best_match`
8. Open `GET /api/opportunities/{id}`
9. `POST /api/opportunities/{id}/save`
10. `GET /api/saved`
11. `POST /api/search/ai`
12. If SearXNG is configured, test `POST /api/search/live`

## 6. Run a full discovery job directly

```bash
python -m app.jobs.daily_sync
```

It should print a JSON run result.

The job:

- loads enabled sources
- discovers URLs
- fetches public pages
- rejects generic listing/index pages as final opportunity cards
- runs deterministic extraction first
- calls Groq only for ambiguous/incomplete pages when configured
- skips AI on unchanged content hashes
- deduplicates/upserts opportunities
- expires dead opportunities
- preserves independent user snapshots
- stores run statistics

## 7. Verify saved-snapshot lifecycle

1. Save an active opportunity.
2. Inspect `saved_opportunities` in MongoDB: it must contain a full `snapshot`.
3. Set the master opportunity deadline to a past UTC date.
4. Run `python -m app.jobs.daily_sync` or invoke cleanup through an ingestion run.
5. The master may be removed when `DELETE_EXPIRED_MASTER=true`.
6. The saved row must remain, with `masterDeleted=true`; `GET /api/saved` should report it as expired.

## 8. Test AI graceful degradation

Remove/comment `GROQ_API_KEY` and restart.

Expected:

- backend still boots
- normal crawling works
- deterministic matching works
- `/api/search/ai` falls back to deterministic natural-language parsing
- `explainAI=true` simply has no generated explanation if Groq is unavailable

## 9. Test SearXNG graceful degradation

Remove/comment `SEARXNG_BASE_URL` and restart.

Expected:

- source-registry crawler still runs
- SearXNG searches return no external candidates rather than crashing the app

## 10. Automated tests

```bash
pytest -q
python -m compileall -q .
```

## 11. Connect the React frontend

Frontend environment:

```env
REACT_APP_BACKEND_URL=http://localhost:8000
```

Never copy `GROQ_API_KEY`, `JWT_SECRET`, or MongoDB credentials to the frontend.

# Orbit — AI Opportunity Radar Backend

FastAPI + MongoDB backend for Orbit. It discovers public student/developer opportunities, normalizes them, ranks them against a user profile, tracks deadlines, and preserves immutable snapshots when users save opportunities.

## What is implemented

- Email/password registration and login with Argon2 + JWT
- Student profile/onboarding persistence
- Opportunity listing, filtering, sorting, match score and eligibility output
- Opportunity detail with optional Groq match explanation
- Save/unsave plus immutable saved snapshots
- Saved statuses: `saved`, `planning`, `applied`; expired/master-deleted state is derived safely
- AI search: Groq when configured, deterministic fallback when not configured
- Live web discovery endpoint
- Public source registry with HTTP/RSS/sitemap/listing discovery
- Optional SearXNG discovery via `SEARXNG_BASE_URL`
- Deterministic extraction before AI: JSON-LD/meta/HTML/regex/date parsing
- Optional Crawl4AI rendered-page fallback (separate optional requirements file)
- Content hashing so unchanged pages skip Groq
- Deduplication by canonical URL and fingerprint
- Daily/manual ingestion pipeline with a singleton MongoDB lock
- Deadline/closed cleanup with saved snapshot preservation
- Ingestion run history and source-health endpoints
- `/health` and database-backed `/ready`
- Zerops daily cron definition

## Runtime

Python 3.11+ (3.12 recommended)

```bash
python -m venv .venv
# Windows
.venv\\Scripts\\activate
# macOS/Linux
source .venv/bin/activate

pip install -r requirements.txt
cp .env.example .env
uvicorn server:app --reload --host 0.0.0.0 --port 8000
```

Swagger docs: `http://localhost:8000/docs`

Health: `http://localhost:8000/health`

Readiness: `http://localhost:8000/ready`

## Required configuration

For local development, only MongoDB must be reachable. Groq and SearXNG are optional.

```env
MONGO_URL=mongodb://localhost:27017
DB_NAME=orbit
JWT_SECRET=<generate-a-long-random-secret>
GROQ_API_KEY=
GROQ_MODEL=openai/gpt-oss-20b
SEARXNG_BASE_URL=
CORS_ORIGINS=http://localhost:3000
```

If `GROQ_API_KEY` is missing, deterministic parsing/matching/search remain available. If `SEARXNG_BASE_URL` is missing, the configured public source registry remains the primary discovery path.

## Daily job

```bash
python -m app.jobs.daily_sync
```

The same command is used by the Zerops cron job.

## Main API routes

- `POST /api/auth/register`
- `POST /api/auth/login`
- `GET /api/auth/me`
- `GET /api/profile`
- `PUT /api/profile`
- `GET /api/opportunities`
- `GET /api/opportunities/{id}`
- `POST /api/opportunities/{id}/save`
- `DELETE /api/opportunities/{id}/save`
- `GET /api/saved`
- `PATCH /api/saved/{saved_id}`
- `GET /api/stats`
- `POST /api/search/ai`
- `POST /api/search/live`
- `GET /api/ingestion/runs`
- `GET /api/ingestion/sources`
- `POST /api/ingestion/run`

See `API_CONTRACT.md` for details.

## Tests

```bash
pip install -r requirements-dev.txt
pytest -q
python -m compileall -q .
```

## Optional Crawl4AI

The normal crawler does **not** require a browser. If you want rendered JavaScript-page fallback locally, install:

```bash
pip install -r requirements-crawl4ai.txt
```

Crawl4AI is imported lazily, so the backend still runs when it is not installed.

## Safety / crawler behavior

- Public HTTP(S) URLs only
- SSRF guard blocks private/loopback hosts
- robots.txt checked by the HTTP fetcher
- conservative per-domain delay
- no CAPTCHA bypass, login scraping, proxy rotation or bot-evasion logic
- official/primary source URLs are preferred

# Orbit Backend — Zerops Deployment

This file covers the FastAPI backend service. The final repository can later use one root `zerops.yaml` for both React + API; the included backend `zerops.yaml` is valid when this backend directory is the deployment working directory.

## Service

Create a Python runtime service named/setup as `api`.

The included configuration uses:

- Python 3.12
- port 8000 with HTTP support
- Uvicorn/FastAPI start command
- `/ready` as deployment readiness check
- `/health` as runtime health check
- one daily cron job at 02:00 UTC

## Runtime environment variables

Add these to the **API service only**:

```env
MONGO_URL=<your MongoDB Atlas URI>
DB_NAME=orbit
JWT_SECRET=<long random secret>
CORS_ORIGINS=https://YOUR-FRONTEND-DOMAIN

GROQ_API_KEY=<add later>
GROQ_MODEL=openai/gpt-oss-20b
SEARXNG_BASE_URL=<optional self-hosted URL>

MAX_AI_CALLS_PER_SYNC=100
MAX_CANDIDATES_PER_RUN=80
MAX_URLS_PER_SOURCE=20
DELETE_EXPIRED_MASTER=true
ALLOW_USER_MANUAL_INGESTION=true
```

Do not expose `MONGO_URL`, `JWT_SECRET`, or `GROQ_API_KEY` to React.

## Daily cron

The included `zerops.yaml` runs:

```bash
python3 -m app.jobs.daily_sync
```

with:

```text
0 2 * * *
```

and `allContainers: false`, so a horizontally scaled API does not run duplicate daily jobs.

## Deploy

When deploying this backend directory directly:

```bash
zcli service push api
```

If this folder is nested in a monorepo, use the Zerops CLI working-directory / YAML-path options or move the final multi-service `zerops.yaml` to repository root.

## Verification after deployment

1. Open `/health`.
2. Open `/ready`; it should be HTTP 200 and show MongoDB connected.
3. Open `/docs`.
4. Register a user.
5. Save a complete profile.
6. Run `POST /api/ingestion/run`.
7. Poll `/api/ingestion/runs/{id}`.
8. Confirm `/api/opportunities` contains normalized records.
9. Add your Groq key and test `/api/search/ai`.
10. Add SearXNG later and test `/api/search/live` for broader discovery.

## Crawl4AI on Zerops

Crawl4AI is intentionally optional because browser dependencies increase deployment size and memory. Start with the default HTTP/BeautifulSoup crawler. If live pages prove that JavaScript rendering is required, install `requirements-crawl4ai.txt` and add the corresponding browser/runtime system dependencies in the Zerops Python runtime preparation step.

import os
import argparse

# --- Configuration ---
EXCLUDED_DIRS = {
    '.git',
    'node_modules',
    '__pycache__',
    '.venv',
    'dist',
    'build',
    '.vscode',
    '.idea',
    '.idx',
    '.next',
    'docs',
    'ui',
    '.env',
    '.env.local'
    'test-reports','venv','__pycache__',
    'Pdf-Scraping',
    'fbr_acts_rules_ordinances',
    'fbr_customs_orders','Instrxctions','useless',
    'fbr_valuation_documents','Sample_Proj','processing_logs','logs',
    'fbr_sros_customs'
}

EXCLUDED_EXTENSIONS = {
    '.png', '.jpg', '.jpeg', '.gif', '.bmp', '.ico', '.svg','.txt',
    '.pdf', '.doc', '.docx', '.xls', '.xlsx',
    '.zip', '.rar', '.gz', '.tar',
    '.exe', '.dll', '.so', '.o', '.jar','.Pdf',',pdf'
    '.mp4', '.mov', '.avi',
    '.mp3', '.wav',
    '.lock'
}

# --- Nayi Tabdeeli: Khaas files jo ignore karni hain ---
EXCLUDED_FILES = {
    'package-lock.json',
    '.env',
    '.env.local'
}

def process_project(root_dir, output_file_path):
    """
    Project ko process karta hai: pehle structure banata hai, phir content.
    Yeh debugging messages bhi print karega.
    """
    print("--- SCRIPT STARTING ---")
    print(f"Project Directory: {os.path.abspath(root_dir)}")
    print(f"Excluded Directories: {EXCLUDED_DIRS}")
    print(f"Excluded Files: {EXCLUDED_FILES}") # Debugging ke liye

    # Pehle purani output file ko delete kar dein (agar maujood hai)
    if os.path.exists(output_file_path):
        os.remove(output_file_path)
        print(f"Deleted old output file: {output_file_path}")

    with open(output_file_path, 'w', encoding='utf-8') as output_file:
        output_file.write("PROJECT STRUCTURE:\n====================\n\n")
        
        # os.walk se sab folders aur files ko process karein
        for root, dirs, files in os.walk(root_dir, topdown=True):
            print(f"\nCurrently in directory: {root}")
            
            # Directories ko filter karein
            original_dirs = list(dirs)
            dirs[:] = [d for d in dirs if d.lower() not in EXCLUDED_DIRS]
            
            skipped_dirs = set(original_dirs) - set(dirs)
            if skipped_dirs:
                for skipped in skipped_dirs:
                    print(f"!!! SKIPPING Directory: {skipped} !!!")
            
            # --- Nayi Tabdeeli: Files ko pehle filter karein ---
            valid_files = []
            for f in sorted(files):
                is_excluded_ext = any(f.lower().endswith(ext) for ext in EXCLUDED_EXTENSIONS)
                is_excluded_file = f.lower() in EXCLUDED_FILES

                if not is_excluded_ext and not is_excluded_file:
                    valid_files.append(f)
                else:
                    print(f"!!! SKIPPING File: {f} !!!")

            # Structure likhein
            level = root.replace(root_dir, '').count(os.sep)
            if level > 0:
                 output_file.write(f"{' ' * 4 * (level-1)}└── {os.path.basename(root)}/\n")
            
            sub_indent = ' ' * 4 * level
            for f in valid_files:
                 output_file.write(f"{sub_indent}    ├── {f}\n")

        output_file.write("\n\nFILE CONTENTS:\n==============\n\n")

        # Dobara walk karein take content likh sakein
        for root, dirs, files in os.walk(root_dir, topdown=True):
            dirs[:] = [d for d in dirs if d.lower() not in EXCLUDED_DIRS]
            
            # Phir content likhein
            for filename in sorted(files):
                is_excluded_ext = any(filename.lower().endswith(ext) for ext in EXCLUDED_EXTENSIONS)
                is_excluded_file = filename.lower() in EXCLUDED_FILES

                if is_excluded_ext or is_excluded_file:
                    continue

                file_path = os.path.join(root, filename)
                relative_path = os.path.relpath(file_path, root_dir)

                try:
                    with open(file_path, 'r', encoding='utf-8', errors='ignore') as f:
                        content = f.read()
                    
                    output_file.write(f"\n--- START OF FILE: {relative_path} ---\n\n")
                    output_file.write(content)
                    output_file.write(f"\n\n--- END OF FILE: {relative_path} ---\n\n" + "="*80 + "\n\n")

                except Exception as e:
                    output_file.write(f"\n--- Could not read file: {relative_path} (Error: {e}) ---\n\n" + "="*80 + "\n\n")

def main():
    parser = argparse.ArgumentParser(description="Combine project files into a single text file with debugging.")
    parser.add_argument("project_dir", type=str, help="Project ka path.")
    parser.add_argument("output_file", type=str, nargs='?', default="combined_project_code.txt", help="Output file ka naam.")
    args = parser.parse_args()

    if not os.path.isdir(args.project_dir):
        print(f"Error: Directory not found at '{args.project_dir}'")
        return
    
    process_project(args.project_dir, args.output_file)
    print(f"\n--- SCRIPT FINISHED ---")
    print(f"Output saved to '{args.output_file}'")

if __name__ == "__main__":
    main()

from __future__ import annotations

import logging
from contextlib import asynccontextmanager

from fastapi import FastAPI, Response, status
from fastapi.middleware.cors import CORSMiddleware

from app.api.router import api_router
from app.config import settings
from app.db import close_client, ensure_indexes, ping_db
from app.services.sources import seed_default_sources
from app.utils.logging import setup_logging

setup_logging()
logger = logging.getLogger("orbit.server")


@asynccontextmanager
async def lifespan(app: FastAPI):
    try:
        await ensure_indexes()
        await seed_default_sources()
    except Exception as exc:
        # App can still start so health/logs expose configuration issues instead
        # of crashing the preview process immediately.
        logger.warning("Startup initialization issue: %s", exc)
    yield
    await close_client()


app = FastAPI(
    title="Orbit — AI Opportunity Radar",
    version="1.0.0",
    lifespan=lifespan,
)

cors_origins = settings.cors_origins
app.add_middleware(
    CORSMiddleware,
    allow_credentials="*" not in cors_origins,
    allow_origins=cors_origins,
    allow_methods=["*"],
    allow_headers=["*"],
)

app.include_router(api_router)


@app.get("/health")
async def health():
    database_ok = await ping_db()
    return {
        "status": "ok" if database_ok else "degraded",
        "database": "connected" if database_ok else "unavailable",
        "groqConfigured": settings.groq_enabled,
        "searxngConfigured": settings.searxng_enabled,
    }


@app.get("/ready")
async def ready(response: Response):
    database_ok = await ping_db()
    if not database_ok:
        response.status_code = status.HTTP_503_SERVICE_UNAVAILABLE
    return {"ready": database_ok, "database": "connected" if database_ok else "unavailable"}


@app.get("/")
async def root():
    return {
        "name": "Orbit — AI Opportunity Radar",
        "api": "/api",
        "health": "/health",
    }

def _env_bool(name: str, default: bool = False) -> bool:
    raw = os.getenv(name)

def _user_response(user: User) -> dict:
    return {
        "id": user.id,
        "email": user.email,
        "fullName": user.fullName,
        "isAdmin": user.isAdmin,
        "onboardingComplete": user.onboardingComplete,
        "createdAt": user.createdAt.isoformat() if user.createdAt else None,
    }


@router.post("/register")
async def register(payload: RegisterRequest, request: Request):
    rate_limit(client_key(request, "register"), 8, 60)
    db = get_db()
    email = payload.email.lower().strip()
    now = datetime.now(timezone.utc)
    user_doc = {
        "email": email,
        "passwordHash": hash_password(payload.password),
        "fullName": payload.fullName.strip() if payload.fullName else None,
        "isAdmin": False,
        "onboardingComplete": False,
        "createdAt": now,
        "updatedAt": now,
    }
    try:
        result = await db.users.insert_one(user_doc)
    except DuplicateKeyError:
        raise HTTPException(status_code=409, detail="An account with this email already exists")

    user_doc["_id"] = result.inserted_id
    user = User.from_mongo(user_doc)
    await db.profiles.update_one(
        {"userId": str(result.inserted_id)},
        {
            "$setOnInsert": {
                "userId": str(result.inserted_id),
                "fullName": payload.fullName,
                "skills": [],
                "interests": [],
                "preferredCategories": [],
                "locationPreference": [],
                "preferredCountries": [],
                "createdAt": now,
            },
            "$set": {"updatedAt": now},
        },
        upsert=True,
    )
    token = create_access_token(str(result.inserted_id), email)
    return {"accessToken": token, "tokenType": "bearer", "user": _user_response(user)}


@router.post("/login")
async def login(payload: LoginRequest, request: Request):
    rate_limit(client_key(request, "login"), 12, 60)
    db = get_db()
    doc = await db.users.find_one({"email": payload.email.lower().strip()})
    if not doc or not verify_password(payload.password, doc.get("passwordHash", "")):
        raise HTTPException(status_code=401, detail="Invalid email or password")
    user = User.from_mongo(doc)
    token = create_access_token(str(doc["_id"]), user.email)
    return {"accessToken": token, "tokenType": "bearer", "user": _user_response(user)}


@router.get("/me")
async def me(user: User = Depends(get_current_user)):
    return _user_response(user)

            "fullName": user.fullName,

            "preferredCategories": [],
            "locationPreference": [],
            "preferredCountries": [],

@profile_router.put("")
async def update_profile(payload: ProfileRequest, user: User = Depends(get_current_user)):
    db = get_db()
    now = datetime.now(timezone.utc)
    data = payload.model_dump()
    data.update({"userId": user.id, "updatedAt": now})
    await db.profiles.update_one(
        {"userId": user.id},
        {"$set": data, "$setOnInsert": {"createdAt": now}},
        upsert=True,
    )
    onboarding_complete = bool(
        payload.country
        and payload.educationLevel
        and payload.skills
        and (payload.preferredCategories or payload.interests)
    )
    user_update = {
        "onboardingComplete": onboarding_complete,
        "updatedAt": now,
    }
    if payload.fullName:
        user_update["fullName"] = payload.fullName
    await db.users.update_one({"_id": ObjectId(user.id)}, {"$set": user_update})
    doc = await db.profiles.find_one({"userId": user.id})
    return serialize(doc)

from __future__ import annotations

from datetime import datetime, timezone

from fastapi import APIRouter, Depends, HTTPException

from app.db import get_db

@router.get("")
async def list_saved(user: User = Depends(get_current_user)):
    docs = await get_db().saved_opportunities.find({"userId": user.id}).sort("savedAt", -1).to_list(500)
    items = []
    now = datetime.now(timezone.utc)
    for doc in docs:
        item = serialize(doc)
        snap = item.get("snapshot") or {}
        deadline = snap.get("deadline")
        expired = False
        if deadline:
            try:
                dt = datetime.fromisoformat(deadline.replace("Z", "+00:00")) if isinstance(deadline, str) else deadline
                if dt and dt.tzinfo is None:
                    dt = dt.replace(tzinfo=timezone.utc)
                expired = bool(dt and dt < now)
            except Exception:
                expired = False
        item["expired"] = bool(item.get("masterDeleted")) or expired
        items.append(item)
    return {"items": items, "total": len(items)}


@router.patch("/{saved_id}")
async def update_saved(
    saved_id: str,
    payload: SavedUpdateRequest,
    user: User = Depends(get_current_user),
):
    oid = object_id(saved_id)
    if not oid:
        raise HTTPException(status_code=404, detail="Saved opportunity not found")
    update = {k: v for k, v in payload.model_dump().items() if v is not None}
    update["updatedAt"] = datetime.now(timezone.utc)
    result = await get_db().saved_opportunities.find_one_and_update(
        {"_id": oid, "userId": user.id},
        {"$set": update},
        return_document=ReturnDocument.AFTER,
    )
    if not result:
        raise HTTPException(status_code=404, detail="Saved opportunity not found")
    return serialize(result)

@save_actions_router.post("/{opportunity_id}/save")
async def save_opportunity(opportunity_id: str, user: User = Depends(get_current_user)):
    db = get_db()
    item = await get_opportunity_for_user(opportunity_id, user.id)
    if not item:
        raise HTTPException(status_code=404, detail="Opportunity not found")
    now = datetime.now(timezone.utc)

    # Snapshot intentionally excludes ephemeral UI-only values where possible,
    # but retains all factual opportunity fields and the match at save time.
    snapshot = dict(item)
    match_score = int(item.get("matchScore") or 0)
    payload = {
        "userId": user.id,
        "originalOpportunityId": opportunity_id,
        "savedAt": now,
        "applicationStatus": "saved",
        "snapshot": snapshot,
        "snapshotMatchScore": match_score,
        "masterDeleted": False,
        "updatedAt": now,
    }
    await db.saved_opportunities.update_one(
        {"userId": user.id, "originalOpportunityId": opportunity_id},
        {"$set": payload},
        upsert=True,
    )
    doc = await db.saved_opportunities.find_one(
        {"userId": user.id, "originalOpportunityId": opportunity_id}
    )
    return serialize(doc)

def _validated_filters(raw: dict) -> OpportunitySearchFilters:
    allowed = {
        "categories": raw.get("categories") or [],
        "countries": raw.get("countries") or [],
        "skills": raw.get("skills") or [],
        "remote": raw.get("remote"),
        "fundingRequired": raw.get("fundingRequired"),
        "deadlineBefore": raw.get("deadlineBefore"),
        "deadlineAfter": raw.get("deadlineAfter"),
        "educationLevels": raw.get("educationLevels") or [],
        "queryText": raw.get("queryText"),
    }
    return OpportunitySearchFilters.model_validate(allowed)


@router.post("/ai")
async def ai_search(payload: AIQueryRequest, user: User = Depends(get_current_user)):
    raw = await query_to_filters(payload.query)
    used_ai = isinstance(raw, dict)
    if not raw:
        raw = deterministic_query_filters(payload.query)

    try:
        filters = _validated_filters(raw)
    except Exception:
        fallback = deterministic_query_filters(payload.query)
        filters = _validated_filters(fallback)
        raw = fallback
        used_ai = False

    results = await list_opportunities(
        user.id,
        q=filters.queryText,
        categories=filters.categories,
        remote=filters.remote,
        funded=filters.fundingRequired,
        deadline_before=filters.deadlineBefore,
        deadline_after=filters.deadlineAfter,
        countries=filters.countries,
        education_levels=filters.educationLevels,
        skills=filters.skills,
        sort="best_match",
        page=1,
        page_size=50,
    )
    return {
        "answer": raw.get("answer")
        or ("AI interpreted your search." if used_ai else "Search completed with deterministic filters."),
        "filters": filters.model_dump(mode="json"),
        "aiConfigured": groq_client.enabled,
        "usedAI": used_ai,
        **results,
    }


@router.post("/live")
async def live_search(payload: LiveSearchRequest, user: User = Depends(get_current_user)):
    run = await run_ingestion(
        trigger="manual",
        query=payload.query or None,
        max_candidates=max(payload.maxResults, 8),
    )
    results = await list_opportunities(
        user.id,
        q=payload.query or None,
        sort="newest",
        page=1,
        page_size=payload.maxResults,
        include_unverified=True,
    )
    return {
        "run": run,
        "query": payload.query,
        "discoveryCompleted": run.get("status") in {"success", "partial"},
        **results,
    }

from fastapi import Depends, HTTPException, Request, status
from fastapi.security import HTTPAuthorizationCredentials, HTTPBearer

from app.auth.security import decode_access_token
from app.config import settings

from app.models.user import User

bearer = HTTPBearer(auto_error=False)

_buckets: dict[str, deque] = defaultdict(deque)


def rate_limit(key: str, limit: int, window_seconds: int) -> None:
    """Simple in-process sliding-window rate limiter."""
    now = time.time()
    bucket = _buckets[key]
    while bucket and now - bucket[0] > window_seconds:
        bucket.popleft()
    if len(bucket) >= limit:
        raise HTTPException(
            status_code=status.HTTP_429_TOO_MANY_REQUESTS,
            detail="Too many requests. Please slow down.",
        )
    bucket.append(now)


def client_key(request: Request, suffix: str) -> str:
    ip = request.headers.get("x-forwarded-for", "").split(",")[0].strip() or (
        request.client.host if request.client else "unknown"
    )
    return f"{suffix}:{ip}"


async def get_current_user(
    credentials: HTTPAuthorizationCredentials | None = Depends(bearer),
) -> User:
    if not credentials:
        raise HTTPException(status_code=401, detail="Not authenticated")
    payload = decode_access_token(credentials.credentials)
    if not payload or not payload.get("sub"):
        raise HTTPException(status_code=401, detail="Invalid or expired token")
    try:
        oid = ObjectId(payload["sub"])
    except (InvalidId, TypeError):
        raise HTTPException(status_code=401, detail="Invalid token subject")
    doc = await get_db().users.find_one({"_id": oid})
    if not doc:
        raise HTTPException(status_code=401, detail="User no longer exists")
    return User.from_mongo(doc)


async def get_admin_user(user: User = Depends(get_current_user)) -> User:
    if user.isAdmin or (settings.admin_email and user.email.lower() == settings.admin_email):
        return user
    raise HTTPException(status_code=403, detail="Admin privileges required")

import secrets
from datetime import datetime, timedelta, timezone

import jwt
from argon2 import PasswordHasher
from argon2.exceptions import VerificationError, VerifyMismatchError

from app.config import settings

_hasher = PasswordHasher()

# Fallback secret is generated per-process so tokens never validate across
# restarts if JWT_SECRET was not configured. Production must set JWT_SECRET.
_RUNTIME_SECRET = settings.jwt_secret or secrets.token_urlsafe(48)


def hash_password(password: str) -> str:
    return _hasher.hash(password)


def verify_password(password: str, password_hash: str) -> bool:
    try:
        return _hasher.verify(password_hash, password)
    except (VerifyMismatchError, VerificationError, ValueError):
        return False


def create_access_token(user_id: str, email: str) -> str:
    now = datetime.now(timezone.utc)
    payload = {
        "sub": user_id,
        "email": email,
        "iat": int(now.timestamp()),
        "exp": int((now + timedelta(minutes=settings.jwt_expire_minutes)).timestamp()),
    }
    return jwt.encode(payload, _RUNTIME_SECRET, algorithm=settings.jwt_algorithm)


def decode_access_token(token: str) -> dict | None:
    try:
        return jwt.decode(token, _RUNTIME_SECRET, algorithms=[settings.jwt_algorithm])
    except jwt.PyJWTError:
        return None

from datetime import datetime, timezone
from typing import Annotated, Any

from bson import ObjectId
from pydantic import BaseModel, BeforeValidator, ConfigDict, Field


def _to_str(v: Any) -> Any:
    if isinstance(v, ObjectId):
        return str(v)
    return v


PyObjectId = Annotated[str, BeforeValidator(_to_str)]


def utcnow() -> datetime:
    return datetime.now(timezone.utc)


class BaseDocument(BaseModel):
    """Base model mapping Mongo `_id` to `id` as a string."""

    model_config = ConfigDict(populate_by_name=True, extra="ignore")

    id: PyObjectId | None = Field(default=None, alias="_id")

    @classmethod
    def from_mongo(cls, doc: dict | None):
        if not doc:
            return None
        return cls.model_validate(doc)

    def to_mongo(self, exclude_none: bool = False) -> dict:
        data = self.model_dump(by_alias=True, exclude_none=exclude_none)
        if data.get("_id") is None:
            data.pop("_id", None)
        return data

from __future__ import annotations

import re
from datetime import datetime, timedelta, timezone

from app.db import get_db
from app.services.matching.engine import score_opportunity
from app.utils.mongo import object_id, serialize


async def get_profile(user_id: str) -> dict:
    return await get_db().profiles.find_one({"userId": user_id}) or {"userId": user_id}


def _funded_query() -> dict:
    return {
        "$and": [
            {"fundingType": {"$ne": None}},
            {"fundingType": {"$nin": ["unpaid", "none", "unknown"]}},
        ]
    }


def build_db_query(
    *,
    q: str | None = None,
    categories: list[str] | None = None,
    remote: bool | None = None,
    funded: bool | None = None,
    deadline_before: datetime | None = None,
    deadline_after: datetime | None = None,
    countries: list[str] | None = None,
    education_levels: list[str] | None = None,
    skills: list[str] | None = None,
    include_unverified: bool = False,
) -> dict:
    clauses: list[dict] = []
    statuses = ["active", "closing_soon"]
    if include_unverified:
        statuses.append("unverified")
    clauses.append({"status": {"$in": statuses}})

    if q and q.strip():
        pattern = re.escape(q.strip()[:120])
        clauses.append(
            {
                "$or": [
                    {"title": {"$regex": pattern, "$options": "i"}},
                    {"organization": {"$regex": pattern, "$options": "i"}},
                    {"description": {"$regex": pattern, "$options": "i"}},
                    {"requiredSkills": {"$regex": pattern, "$options": "i"}},
                ]
            }
        )
    if categories:
        clauses.append({"category": {"$in": categories}})
    if remote is not None:
        clauses.append({"remote": remote})
    if funded is True:
        clauses.append(_funded_query())
    if funded is False:
        clauses.append(
            {"$or": [{"fundingType": None}, {"fundingType": {"$in": ["unpaid", "none", "unknown"]}}]}
        )
    deadline_clause = {}
    if deadline_before:
        deadline_clause["$lte"] = deadline_before
    if deadline_after:
        deadline_clause["$gte"] = deadline_after
    if deadline_clause:
        clauses.append({"deadline": deadline_clause})
    if countries:
        lowered = [re.escape(x) for x in countries if x]
        if lowered:
            clauses.append(
                {
                    "$or": [
                        {"countriesEligible": {"$regex": "|".join(lowered), "$options": "i"}},
                        {
                            "countriesEligible": {
                                "$in": ["Global", "Worldwide", "International", "All countries"]
                            }
                        },
                        {"countriesEligible": {"$size": 0}},
                        {"countriesEligible": {"$exists": False}},
                    ]
                }
            )
    if education_levels:
        clauses.append(
            {
                "$or": [
                    {"educationLevels": {"$in": education_levels}},
                    {"educationLevels": {"$size": 0}},
                    {"educationLevels": {"$exists": False}},
                ]
            }
        )
    if skills:
        skill_patterns = [re.escape(x) for x in skills if x][:12]
        if skill_patterns:
            clauses.append(
                {
                    "$or": [
                        {"requiredSkills": {"$regex": pattern, "$options": "i"}}
                        for pattern in skill_patterns
                    ]
                    + [
                        {"preferredSkills": {"$regex": pattern, "$options": "i"}}
                        for pattern in skill_patterns
                    ]
                }
            )
    return {"$and": clauses} if len(clauses) > 1 else clauses[0]


def enrich_opportunity(doc: dict, profile: dict | None = None) -> dict:
    raw = serialize(doc)
    match = score_opportunity(doc, profile or {})
    raw["match"] = match
    raw["matchScore"] = match["matchScore"]
    raw["eligibilityStatus"] = match["eligibilityStatus"]
    raw["matchedSkills"] = match["matchedSkills"]
    raw["missingSkills"] = match["missingSkills"]
    raw["matchingReasons"] = match["matchingReasons"]
    deadline = doc.get("deadline")
    if deadline:
        if deadline.tzinfo is None:
            deadline = deadline.replace(tzinfo=timezone.utc)
        raw["daysRemaining"] = max(-1, int((deadline - datetime.now(timezone.utc)).total_seconds() // 86400))
    else:
        raw["daysRemaining"] = None
    raw["applyUrl"] = raw.get("applicationUrl") or raw.get("sourceUrl")
    return raw


async def list_opportunities(
    user_id: str,
    *,
    q: str | None = None,
    categories: list[str] | None = None,
    remote: bool | None = None,
    funded: bool | None = None,
    deadline_before: datetime | None = None,
    deadline_after: datetime | None = None,
    countries: list[str] | None = None,
    education_levels: list[str] | None = None,
    skills: list[str] | None = None,
    min_match: int = 0,
    sort: str = "best_match",
    page: int = 1,
    page_size: int = 20,
    include_unverified: bool = False,
) -> dict:
    db = get_db()
    profile = await get_profile(user_id)
    query = build_db_query(
        q=q,
        categories=categories,
        remote=remote,
        funded=funded,
        deadline_before=deadline_before,
        deadline_after=deadline_after,
        countries=countries,
        education_levels=education_levels,
        skills=skills,
        include_unverified=include_unverified,
    )

    # Fetch a bounded pool because match score is user-specific and computed in Python.
    docs = await db.opportunities.find(query).sort("createdAt", -1).limit(500).to_list(500)
    items = [enrich_opportunity(doc, profile) for doc in docs]
    if min_match:
        items = [x for x in items if int(x.get("matchScore") or 0) >= min_match]

    if sort == "deadline":
        items.sort(key=lambda x: (x.get("deadline") is None, x.get("deadline") or "9999"))
    elif sort == "newest":
        items.sort(key=lambda x: x.get("createdAt") or "", reverse=True)
    else:
        items.sort(key=lambda x: int(x.get("matchScore") or 0), reverse=True)

    total = len(items)
    start = max(0, (page - 1) * page_size)
    return {
        "items": items[start : start + page_size],
        "total": total,
        "page": page,
        "pageSize": page_size,
    }


async def get_opportunity_for_user(opportunity_id: str, user_id: str) -> dict | None:
    oid = object_id(opportunity_id)
    if not oid:
        return None
    doc = await get_db().opportunities.find_one({"_id": oid})
    if not doc:
        return None
    profile = await get_profile(user_id)
    return enrich_opportunity(doc, profile)


async def dashboard_stats(user_id: str) -> dict:
    db = get_db()
    profile = await get_profile(user_id)
    docs = await db.opportunities.find(
        {"status": {"$in": ["active", "closing_soon"]}}
    ).sort("createdAt", -1).limit(500).to_list(500)
    enriched = [enrich_opportunity(x, profile) for x in docs]
    now = datetime.now(timezone.utc)
    today = now - timedelta(hours=24)
    recommended = sum(1 for x in enriched if x["matchScore"] >= 70)
    closing = sum(
        1
        for x in enriched
        if x.get("daysRemaining") is not None and 0 <= x["daysRemaining"] <= 7
    )
    new_today = 0
    for doc in docs:
        created = doc.get("createdAt")
        if created and created.tzinfo is None:
            created = created.replace(tzinfo=timezone.utc)
        if created and created >= today:
            new_today += 1

from app.models.opportunity import CATEGORIES

def deterministic_query_filters(query: str) -> dict:
    text = (query or "").strip()
    lowered = text.lower()
    categories = []
    aliases = {
        "scholarship": ("scholarship", "scholarships", "bursary"),
        "internship": ("internship", "internships", "intern"),
        "fellowship": ("fellowship", "fellowships"),
        "hackathon": ("hackathon", "hackathons"),
        "grant": ("grant", "grants"),
        "competition": ("competition", "competitions", "contest", "challenge"),
        "research": ("research", "research program", "research programme"),
        "open_source": ("open source", "gsoc", "outreachy"),
        "developer_program": ("developer program", "developer programme", "ambassador"),
        "mentorship": ("mentorship", "mentor program", "mentoring"),
    }
    for category, terms in aliases.items():
        if any(term in lowered for term in terms):
            categories.append(category)

    skills = []
    for skill in SKILL_VOCAB:
        if re.search(r"(?<![a-z0-9])" + re.escape(skill.lower()) + r"(?![a-z0-9])", lowered):
            skills.append(skill)

    remote = True if "remote" in lowered or "work from home" in lowered else None
    funding_required = True if any(
        term in lowered
        for term in ("fully funded", "funded", "stipend", "paid", "scholarship")
    ) else None

    deadline_before = None
    m = re.search(r"(?:next|within)\s+(\d{1,3})\s+days", lowered)
    if m:
        deadline_before = datetime.now(timezone.utc) + timedelta(days=min(int(m.group(1)), 365))

    return {
        "categories": categories,
        "countries": [],
        "skills": skills,
        "remote": remote,
        "fundingRequired": funding_required,
        "deadlineBefore": deadline_before,
        "deadlineAfter": None,
        "educationLevels": [],
        "queryText": text if not categories and not skills else None,
        "answer": f"Filtered opportunities using the available profile and query terms: {text}",
    }

RELEVANCE_TERMS = (
    "scholarship",
    "internship",
    "fellowship",
    "hackathon",
    "grant",
    "competition",
    "programme",
    "program",
    "mentorship",
    "apply",
    "application",
    "deadline",
    "funded",
    "bursary",
    "residency",
)

NEGATIVE_TERMS = ("login", "signin", "cart", "pricing", "casino", "porn", "job board review")


def is_relevant(title: str, snippet: str, url: str) -> bool:
    """Lightweight relevance classifier — SearXNG results are candidates, not data."""
    blob = f"{title} {snippet} {url}".lower()
    if any(term in blob for term in NEGATIVE_TERMS):
        return False
    hits = sum(1 for term in RELEVANCE_TERMS if term in blob)
    return hits >= 2


async def search(query: str, max_results: int = 10) -> list[dict]:
    if not settings.searxng_enabled:
        return []
    params = {"q": query, "format": "json", "language": "en", "safesearch": "1"}
    try:
        async with httpx.AsyncClient(
            timeout=settings.scraper_timeout,
            headers={"User-Agent": settings.scraper_user_agent},
            follow_redirects=True,
        ) as client:
            resp = await client.get(f"{settings.searxng_base_url}/search", params=params)
            resp.raise_for_status()
            data = resp.json()
    except (httpx.HTTPError, ValueError) as exc:
        logger.warning("SearXNG unavailable (%s) — skipping live discovery", exc)
        return []

    out: list[dict] = []
    for item in data.get("results", [])[: max_results * 3]:
        url = canonicalize_url(item.get("url", ""))
        title = item.get("title", "") or ""
        snippet = item.get("content", "") or ""
        if not url or not looks_like_content_url(url):
            continue
        if not is_relevant(title, snippet, url):
            continue
        if not is_public_http_url(url):
            continue
        out.append({"url": url, "title": title, "snippet": snippet})
        if len(out) >= max_results:
            break
    return out

"""Groq API client — structured JSON reasoning layer.

Fully env-var driven. If GROQ_API_KEY is absent, `enabled` is False and every
caller degrades gracefully (returns None) instead of raising.
"""

import asyncio
import json
import logging

import httpx

from app.config import settings

logger = logging.getLogger("orbit.ai.groq")


class GroqClient:
    def __init__(self) -> None:
        self.api_key = settings.groq_api_key
        self.model = settings.groq_model
        self.base_url = settings.groq_base_url
        self.timeout = settings.groq_timeout
        self.calls_made = 0

    @property
    def enabled(self) -> bool:
        return bool(self.api_key)

    async def json_completion(
        self,
        system: str,
        user: str,
        max_tokens: int = 1200,
        temperature: float = 0.1,
        retries: int = 3,
    ) -> dict | None:
        """Request a JSON object completion. Returns parsed dict or None."""
        if not self.enabled:
            return None

        payload = {
            "model": self.model,
            "messages": [
                {"role": "system", "content": system},
                {"role": "user", "content": user},
            ],
            "response_format": {"type": "json_object"},
            "temperature": temperature,
            "max_tokens": max_tokens,
        }
        headers = {
            "Authorization": f"Bearer {self.api_key}",
            "Content-Type": "application/json",
        }

        backoff = 1.5
        for attempt in range(retries):
            try:
                async with httpx.AsyncClient(timeout=self.timeout) as client:
                    resp = await client.post(
                        f"{self.base_url}/chat/completions", json=payload, headers=headers
                    )
                if resp.status_code == 429:
                    await asyncio.sleep(backoff * (2**attempt))
                    continue
                if resp.status_code >= 400:
                    logger.warning("Groq error %s: %s", resp.status_code, resp.text[:300])
                    if resp.status_code >= 500:
                        await asyncio.sleep(backoff * (2**attempt))
                        continue
                    return None
                self.calls_made += 1
                content = resp.json()["choices"][0]["message"]["content"]
                return json.loads(content)
            except (httpx.HTTPError, json.JSONDecodeError, KeyError, IndexError) as exc:
                logger.warning("Groq request failed (attempt %s): %s", attempt + 1, exc)
                await asyncio.sleep(backoff * (2**attempt))
        return None


groq_client = GroqClient()

"""Deterministic matching engine — no LLM calls per user/opportunity pair.

Weights (total 100):
  skills 28 | eligibility/country 25 | category preference 14
  education 10 | location/remote 8 | experience 5 | deadline usefulness 5 | funding 5
Unknown data is treated as neutral (partial credit), never as a failure.
"""

from app.utils.dates import days_remaining
from app.utils.text import normalize_text

WEIGHTS = {
    "skills": 28.0,
    "eligibility": 25.0,
    "category": 14.0,
    "education": 10.0,
    "location": 8.0,
    "experience": 5.0,
    "deadline": 5.0,
    "funding": 5.0,
}

GLOBAL_MARKERS = {"global", "worldwide", "any country", "international", "all countries", "open"}

EXPERIENCE_ORDER = ["student", "beginner", "entry", "junior", "mid", "senior"]


def _norm_set(values) -> set[str]:
    return {normalize_text(v) for v in (values or []) if v and normalize_text(v)}


def _skill_score(profile_skills: set[str], required: set[str], preferred: set[str]):
    target = required | preferred
    if not target:
        return 0.6, [], []
    matched = sorted(target & profile_skills)
    missing = sorted(required - profile_skills)
    if not profile_skills:
        return 0.4, matched, missing
    required_ratio = len(required & profile_skills) / len(required) if required else None
    overall_ratio = len(matched) / len(target)
    ratio = overall_ratio if required_ratio is None else (0.7 * required_ratio + 0.3 * overall_ratio)
    return min(1.0, 0.15 + 0.85 * ratio), matched, missing


def _eligibility(country: str | None, eligible: list[str]):
    normalized = _norm_set(eligible)
    if not normalized:
        return 0.6, "uncertain", "Eligible countries are not stated on the source page"
    if normalized & GLOBAL_MARKERS:
        return 1.0, "eligible", "Open to applicants worldwide"
    if not country:
        return 0.5, "uncertain", "Add your country to your profile for eligibility checks"
    c = normalize_text(country)
    for item in normalized:
        if c == item or c in item or item in c:
            return 1.0, "eligible", f"Applicants from {country} are accepted"
    return 0.15, "likely_ineligible", f"{country} is not listed among eligible countries"


def _category(preferred: list[str], category: str | None):
    if not preferred:
        return 0.7, None
    if category and category in {p.strip().lower() for p in preferred}:
        return 1.0, f"Matches your interest in {category.replace('_', ' ')} opportunities"
    return 0.3, None


def _education(level: str | None, levels: list[str]):
    normalized = _norm_set(levels)
    if not normalized:
        return 0.65, None
    if not level:
        return 0.5, None
    n = normalize_text(level)
    for item in normalized:
        if n == item or n in item or item in n:
            return 1.0, f"Open to {level} students"
    return 0.35, None


def _location(prefs: list[str], opp: dict):
    prefs_n = {normalize_text(p) for p in (prefs or [])}
    if not prefs_n:
        return 0.7, None
    if "global" in prefs_n:
        return 1.0, None
    if opp.get("remote") and "remote" in prefs_n:
        return 1.0, "Fully remote, matching your preference"
    if opp.get("hybrid") and "hybrid" in prefs_n:
        return 0.9, "Hybrid participation available"
    if opp.get("onsite") and "onsite" in prefs_n:
        return 0.85, None
    if opp.get("remote") is None and opp.get("hybrid") is None and opp.get("onsite") is None:
        return 0.6, None
    return 0.35, None


def _experience(level: str | None, levels: list[str]):
    normalized = _norm_set(levels)
    if not normalized or not level:
        return 0.65, None
    n = normalize_text(level)
    if any(n == item or n in item or item in n for item in normalized):
        return 1.0, f"Suited to {level} experience level"
    return 0.4, None


def _deadline(deadline):
    days = days_remaining(deadline)
    if days is None:
        return 0.5, None
    if days < 0:
        return 0.0, "Deadline has passed"
    if days <= 7:
        return 1.0, f"Closing in {days} day(s) — apply soon"
    if days <= 45:
        return 0.9, f"{days} days left to apply"
    if days <= 180:
        return 0.7, f"{days} days left to apply"
    return 0.5, None



def _funding(preference: str | None, funding_type: str | None):
    pref = normalize_text(preference)
    funding = normalize_text(funding_type)
    if not pref or pref in {"any", "unfunded ok", "unfunded_ok"}:
        return 0.7, None
    if pref in {"funded only", "funded_only", "fully funded", "funded"}:
        if not funding:
            return 0.5, "Funding is not clearly stated"
        if funding in {"unpaid", "none", "unfunded"}:
            return 0.0, "This appears to be unfunded"
        return 1.0, f"Funding preference matched: {funding_type}"
    return 0.7, None


def _display_skill(value: str) -> str:
    special = {
        "ai": "AI", "nlp": "NLP", "sql": "SQL", "aws": "AWS",
        "ui ux": "UI/UX", "c++": "C++", "c#": "C#", "node js": "Node.js",
        "javascript": "JavaScript", "typescript": "TypeScript",
    }
    return special.get(value, value.title())


def score_opportunity(opportunity: dict, profile: dict | None) -> dict:
    profile = profile or {}
    profile_skills = _norm_set(profile.get("skills")) | _norm_set(profile.get("interests"))

    skill_s, matched, missing = _skill_score(
        profile_skills,
        _norm_set(opportunity.get("requiredSkills")),
        _norm_set(opportunity.get("preferredSkills")),
    )
    elig_s, elig_status, elig_reason = _eligibility(
        profile.get("country"), opportunity.get("countriesEligible") or []
    )
    cat_s, cat_reason = _category(
        profile.get("preferredCategories") or [], opportunity.get("category")
    )
    edu_s, edu_reason = _education(
        profile.get("educationLevel"), opportunity.get("educationLevels") or []
    )
    loc_s, loc_reason = _location(profile.get("locationPreference") or [], opportunity)
    exp_s, exp_reason = _experience(
        profile.get("experienceLevel"), opportunity.get("experienceLevels") or []
    )
    dl_s, dl_reason = _deadline(opportunity.get("deadline"))
    fund_s, fund_reason = _funding(profile.get("fundingPreference"), opportunity.get("fundingType"))

    breakdown = {
        "skills": round(skill_s * WEIGHTS["skills"], 1),
        "eligibility": round(elig_s * WEIGHTS["eligibility"], 1),
        "category": round(cat_s * WEIGHTS["category"], 1),
        "education": round(edu_s * WEIGHTS["education"], 1),
        "location": round(loc_s * WEIGHTS["location"], 1),
        "experience": round(exp_s * WEIGHTS["experience"], 1),
        "deadline": round(dl_s * WEIGHTS["deadline"], 1),
        "funding": round(fund_s * WEIGHTS["funding"], 1),
    }
    total = int(round(sum(breakdown.values())))

    if elig_status == "eligible" and total >= 70:
        eligibility_status = "eligible"
    elif elig_status == "likely_ineligible":
        eligibility_status = "likely_ineligible"
    elif elig_status == "eligible":
        eligibility_status = "likely_eligible"
    else:
        eligibility_status = "uncertain"

    reasons = []
    if matched:
        reasons.append("Skill overlap: " + ", ".join(sorted(matched)[:4]))
    for reason in (elig_reason, cat_reason, edu_reason, loc_reason, exp_reason, dl_reason, fund_reason):
        if reason:
            reasons.append(reason)
    if opportunity.get("fundingType") and not fund_reason:
        reasons.append(f"Funding: {opportunity['fundingType']}")

    return {
        "matchScore": max(0, min(100, total)),
        "eligibilityStatus": eligibility_status,
        "matchedSkills": [_display_skill(s) for s in matched][:12],
        "missingSkills": [_display_skill(s) for s in missing][:12],
        "matchingReasons": reasons[:6],
        "breakdown": breakdown,
    }

"""Duplicate detection: canonical URL first, then organization+title+deadline fingerprint."""

from motor.motor_asyncio import AsyncIOMotorDatabase

from app.models.opportunity import Opportunity


async def find_existing(db: AsyncIOMotorDatabase, opportunity: Opportunity) -> dict | None:
    doc = await db.opportunities.find_one({"canonicalUrl": opportunity.canonicalUrl})
    if doc:
        return doc
    if opportunity.fingerprint:
        return await db.opportunities.find_one({"fingerprint": opportunity.fingerprint})
    return None


def is_duplicate_of(existing: dict, opportunity: Opportunity) -> bool:
    """True when the record matches by fingerprint but has a different URL."""
    return (
        bool(existing.get("fingerprint"))
        and existing.get("fingerprint") == opportunity.fingerprint
        and existing.get("canonicalUrl") != opportunity.canonicalUrl
    )

from __future__ import annotations

import logging
import re
import xml.etree.ElementTree as ET
from urllib.parse import urljoin, urlparse

from bs4 import BeautifulSoup

from app.config import settings
from app.services.scrapper.fetcher import fetch
from app.services.searxng import search as searxng_search
from app.utils.urls import canonicalize_url, is_public_http_url, looks_like_content_url

logger = logging.getLogger("orbit.scraper.discovery")

OPPORTUNITY_TERMS = (
    "scholarship", "internship", "fellowship", "hackathon", "grant", "competition",
    "research", "student", "program", "programme", "mentorship", "apply",
    "application", "opportunity", "traineeship", "award",
)


def _candidate_score(text: str, url: str) -> int:
    blob = f"{text} {url}".lower()
    return sum(1 for term in OPPORTUNITY_TERMS if term in blob)


def _allow_candidate(url: str, anchor_text: str, source_url: str, allow_external: bool = False) -> bool:
    if not url or not looks_like_content_url(url):
        return False
    parsed = urlparse(url)
    source = urlparse(source_url)
    same_domain = (
        parsed.netloc.lower().removeprefix("www.")
        == source.netloc.lower().removeprefix("www.")
    )
    if not same_domain and not allow_external:
        return False
    minimum_score = 1 if same_domain else 2
    return _candidate_score(anchor_text, url) >= minimum_score


async def discover_listing(source: dict, max_results: int) -> list[dict]:
    result = await fetch(
        source["baseUrl"],
        crawl_delay=float(source.get("crawlDelay") or settings.scraper_default_delay),
    )
    if not result.ok or not result.html:
        raise RuntimeError(result.error or f"listing fetch failed ({result.status})")
    soup = BeautifulSoup(result.html, "lxml")
    selector = source.get("listingSelector")
    anchors = soup.select(selector) if selector else soup.find_all("a", href=True)
    out, seen = [], set()
    for anchor in anchors:
        href = anchor.get("href") if hasattr(anchor, "get") else None
        if not href:
            continue
        absolute = canonicalize_url(urljoin(result.url, href))
        text = " ".join(anchor.stripped_strings) if hasattr(anchor, "stripped_strings") else ""
        if not absolute or absolute in seen:
            continue
        if not _allow_candidate(
            absolute,
            text,
            result.url,
            bool(source.get("allowExternal")),
        ):
            continue
        if not is_public_http_url(absolute):
            continue
        seen.add(absolute)
        out.append({"url": absolute, "title": text[:180], "sourceType": "listing"})
        if len(out) >= max_results:
            break
    # A source page can itself be a concrete opportunity/program (NASA/Outreachy).
    # Include it so deterministic extraction has a chance to normalize it.
    base = canonicalize_url(result.url)
    if source.get("includeBase") and base and base not in seen:
        out.insert(0, {"url": base, "title": source.get("name", ""), "sourceType": "listing"})
    return out[:max_results]


async def discover_xml(source: dict, max_results: int) -> list[dict]:
    result = await fetch(
        source["baseUrl"],
        crawl_delay=float(source.get("crawlDelay") or settings.scraper_default_delay),
        respect_robots=True,
    )
    if not result.ok or not result.html:
        raise RuntimeError(result.error or f"XML fetch failed ({result.status})")
    try:
        root = ET.fromstring(result.html)
    except ET.ParseError as exc:
        raise RuntimeError(f"invalid XML: {exc}") from exc

    out, seen = [], set()
    dtype = source.get("discoveryType")
    if dtype == "rss":
        nodes = root.findall(".//item") + root.findall(".//{*}entry")
        for node in nodes:
            link = node.findtext("link")
            if not link:
                link_el = node.find("{*}link")
                if link_el is not None:
                    link = link_el.attrib.get("href") or link_el.text
            title = node.findtext("title") or node.findtext("{*}title") or ""
            url = canonicalize_url(urljoin(result.url, link or ""))
            if not url or url in seen or not is_public_http_url(url) or not looks_like_content_url(url):
                continue
            seen.add(url)
            out.append({"url": url, "title": title[:180], "sourceType": "rss"})
            if len(out) >= max_results:
                break
    else:
        for loc in root.findall(".//{*}loc"):
            url = canonicalize_url((loc.text or "").strip())
            if not url or url in seen or not is_public_http_url(url) or not looks_like_content_url(url):
                continue
            if _candidate_score("", url) < 1:
                continue
            seen.add(url)
            out.append({"url": url, "title": "", "sourceType": "sitemap"})
            if len(out) >= max_results:
                break
    return out


async def discover_source(source: dict, max_results: int | None = None) -> list[dict]:
    max_results = max_results or settings.max_urls_per_source
    dtype = source.get("discoveryType", "listing")
    if dtype in {"rss", "sitemap"}:
        return await discover_xml(source, max_results)
    if dtype == "searxng":
        query = (source.get("queries") or [source.get("name", "student opportunities")])[0]
        return [
            {**item, "sourceType": "searxng"}
            for item in await searxng_search(query, max_results=max_results)
        ]
    return await discover_listing(source, max_results)


async def discover_query(query: str, max_results: int = 20) -> list[dict]:
    if settings.searxng_enabled and query.strip():
        items = await searxng_search(query.strip(), max_results=max_results)
        if items:
            return [{**item, "sourceType": "searxng"} for item in items]
    return []

def _soup(html: str) -> BeautifulSoup:
    try:
        return BeautifulSoup(html, "lxml")
    except Exception:
        return BeautifulSoup(html, "html.parser")


def page_text(html: str) -> tuple[str, BeautifulSoup]:
    soup = _soup(html)
    for tag in soup(["script", "style", "nav", "footer", "header", "form", "noscript", "svg"]):
        tag.decompose()
    main = soup.find("article") or soup.find("main") or soup.body or soup
    return strip_html(main.get_text(" ")), soup


def extract_jsonld(soup: BeautifulSoup) -> dict:
    """Parse schema.org JSON-LD blocks for the most useful opportunity types."""
    out: dict = {}
    for script in soup.find_all("script", attrs={"type": "application/ld+json"}):
        raw = script.string or script.get_text() or ""
        try:
            data = json.loads(raw)
        except (json.JSONDecodeError, TypeError):
            continue
        nodes = data if isinstance(data, list) else [data]
        if isinstance(data, dict) and isinstance(data.get("@graph"), list):
            nodes = data["@graph"]
        for node in nodes:
            if not isinstance(node, dict):
                continue
            types = node.get("@type")
            types = [types] if isinstance(types, str) else (types or [])
            types = [t.lower() for t in types if isinstance(t, str)]
            if any(t in ("jobposting", "event", "educationaloccupationalprogram", "course", "article", "newsarticle", "blogposting", "webpage") for t in types):
                out.setdefault("title", node.get("title") or node.get("name") or node.get("headline"))
                desc = node.get("description")
                if desc:
                    out.setdefault("description", strip_html(desc))
                org = node.get("hiringOrganization") or node.get("organizer") or node.get("provider") or node.get("publisher")
                if isinstance(org, dict):
                    out.setdefault("organization", org.get("name"))
                elif isinstance(org, str):
                    out.setdefault("organization", org)
                deadline = (
                    node.get("applicationDeadline")
                    or node.get("validThrough")
                    or node.get("endDate")
                )
                if deadline:
                    out.setdefault("deadlineRaw", str(deadline))
                start = node.get("datePosted") or node.get("startDate")
                if start:
                    out.setdefault("applicationOpenRaw", str(start))
                loc = node.get("jobLocation") or node.get("location")
                if isinstance(loc, dict):
                    addr = loc.get("address")
                    if isinstance(addr, dict):
                        parts = [addr.get("addressLocality"), addr.get("addressCountry")]
                        text = ", ".join([p for p in parts if isinstance(p, str)])
                        if text:
                            out.setdefault("locations", [text])
                    elif isinstance(loc.get("name"), str):
                        out.setdefault("locations", [loc["name"]])
                if node.get("jobLocationType") == "TELECOMMUTE":
                    out.setdefault("remote", True)
    return {k: v for k, v in out.items() if v}


def extract_meta(soup: BeautifulSoup) -> dict:
    out: dict = {}

    def meta(*names: str) -> str | None:
        for name in names:
            tag = soup.find("meta", attrs={"property": name}) or soup.find(
                "meta", attrs={"name": name}
            )
            if tag and tag.get("content"):
                return tag["content"].strip()
        return None

    out["title"] = meta("og:title", "twitter:title") or (
        soup.title.get_text().strip() if soup.title else None
    )
    out["description"] = meta("og:description", "description", "twitter:description")
    out["organization"] = meta("og:site_name", "author")
    canonical = soup.find("link", attrs={"rel": "canonical"})
    if canonical and canonical.get("href"):
        out["canonical"] = canonical["href"].strip()
    return {k: v for k, v in out.items() if v}


def guess_category(text: str, hint: str | None = None) -> str:
    lowered = text.lower()[:6000]
    best, best_hits = hint or "other", 0
    for category, keywords in CATEGORY_KEYWORDS.items():
        hits = sum(lowered.count(k) for k in keywords)
        if hits > best_hits:
            best, best_hits = category, hits
    if best_hits == 0 and hint:
        return hint
    return best


def extract_skills(text: str) -> list[str]:
    lowered = text.lower()
    found = []
    for skill in SKILL_VOCAB:
        token = skill.lower()
        pattern = r"(?<![a-z0-9])" + re.escape(token) + r"(?![a-z0-9])"
        if re.search(pattern, lowered):
            found.append(skill)
    return found[:15]


def extract_education_levels(text: str) -> list[str]:
    lowered = text.lower()
    return [level for level, terms in EDUCATION_VOCAB.items() if any(t in lowered for t in terms)]


def extract_fields(text: str) -> list[str]:
    lowered = text.lower()
    return [f for f in FIELD_VOCAB if f.lower() in lowered][:8]


def extract_countries(text: str) -> list[str]:
    if GLOBAL_RE.search(text):
        return ["Global"]
    lowered = text.lower()
    found = []
    for country in COUNTRY_LIST:
        if re.search(r"(?<![a-z])" + re.escape(country.lower()) + r"(?![a-z])", lowered):
            found.append(country)
    return found[:15]


def extract_funding(text: str) -> tuple[str | None, float | None, str | None]:
    lowered = text.lower()
    funding_type = None
    for pattern, label in FUNDING_PATTERNS:
        if re.search(pattern, lowered):
            funding_type = label
            break
    amount, currency = None, None
    match = AMOUNT_RE.search(text)
    if match:
        symbol = (match.group(1) or match.group(4) or "").lower()
        raw = match.group(2) or match.group(3) or ""
        try:
            amount = float(raw.replace(",", ""))
        except ValueError:
            amount = None
        currency = CURRENCY_MAP.get(symbol, symbol.upper() or None)
        if amount is not None and amount < 100:
            amount, currency = None, None
    return funding_type, amount, currency


def extract_bullets(soup: BeautifulSoup, keywords: tuple[str, ...]) -> list[str]:
    """Find list items under headings matching the given keywords."""
    out: list[str] = []
    for heading in soup.find_all(["h1", "h2", "h3", "h4", "strong", "b"]):
        label = heading.get_text(" ").strip().lower()
        if not label or len(label) > 90:
            continue
        if not any(k in label for k in keywords):
            continue
        node = heading.find_next(["ul", "ol", "p"])
        if not node:
            continue
        if node.name in ("ul", "ol"):
            for li in node.find_all("li", limit=BULLET_LIMIT):
                value = strip_html(li.get_text(" "))
                if 8 < len(value) < 300:
                    out.append(value)
        else:
            value = strip_html(node.get_text(" "))
            if 15 < len(value) < 400:
                out.append(value)
        if len(out) >= BULLET_LIMIT:
            break
    seen, unique = set(), []
    for item in out:
        if item.lower() not in seen:
            seen.add(item.lower())
            unique.append(item)
    return unique[:BULLET_LIMIT]



def extract_application_url(soup: BeautifulSoup, base_url: str) -> str | None:
    """Find the most likely public application/registration URL on the page."""
    from urllib.parse import urljoin

    best: tuple[int, str] | None = None
    for anchor in soup.find_all("a", href=True):
        href = (anchor.get("href") or "").strip()
        if not href or href.startswith(("#", "mailto:", "tel:", "javascript:")):
            continue
        label = strip_html(anchor.get_text(" ")).lower()
        target = urljoin(base_url, href)
        blob = f"{label} {target}".lower()
        score = 0
        if "apply" in label:
            score += 6
        if "application" in label:
            score += 5
        if "register" in label or "registration" in label:
            score += 4
        if any(x in blob for x in ("apply", "application", "register", "submission")):
            score += 2
        if "login" in blob or "sign in" in label:
            score -= 3
        if score > 0 and (best is None or score > best[0]):
            best = (score, target)
    return best[1] if best else None


GENERIC_LISTING_TITLE_TERMS = (
    "opportunities for individuals",
    "scholarship database",
    "search scholarships",
    "all internships",
    "all opportunities",
    "events calendar",
    "programmes and opportunities",
    "programs and opportunities",
)


def concrete_opportunity_score(result: dict) -> int:
    """Score whether deterministic extraction resembles one concrete apply-able item.

    This intentionally favours precision over recall. Ambiguous pages may still be
    accepted later when Groq explicitly classifies them as an opportunity.
    """
    title = (result.get("title") or "").strip().lower()
    if any(term in title for term in GENERIC_LISTING_TITLE_TERMS):
        return -3

    score = 0
    if result.get("applicationUrl"):
        score += 3
    if result.get("deadline"):
        score += 3
    if result.get("requirements") or result.get("eligibilityText"):
        score += 2
    if result.get("fundingType"):
        score += 1
    if result.get("countriesEligible") or result.get("educationLevels"):
        score += 1
    if result.get("usedJsonLd"):
        score += 1
    category = result.get("category")
    if category and category != "other":
        score += 1
    if result.get("closedMarker"):
        score += 1
    return score


def is_likely_concrete_opportunity(result: dict) -> bool:
    return concrete_opportunity_score(result) >= 3


def deterministic_extract(url: str, html: str, category_hint: str | None = None) -> dict:
    """Run the whole deterministic chain and report extraction confidence."""
    text, raw_soup = page_text(html)
    soup = _soup(html)

    jsonld = extract_jsonld(soup)
    meta = extract_meta(soup)

    title = jsonld.get("title") or meta.get("title")
    if title:
        title = re.split(r"\s+[|\u2013\u2014-]\s+", title)[0].strip()[:220]

    h1 = soup.find("h1")
    if (not title or len(title) < 8) and h1:
        title = strip_html(h1.get_text(" "))[:220]

    description = sanitize_display(jsonld.get("description") or meta.get("description")) or truncate(
        text, 900
    )
    signal_text = f"{title or ''} {description or ''} {text}"

    deadline = parse_date(jsonld.get("deadlineRaw")) if jsonld.get("deadlineRaw") else None
    deadline_text = jsonld.get("deadlineRaw") if deadline else None
    if not deadline:
        deadline, deadline_text = extract_deadline(signal_text)

    funding_type, funding_amount, currency = extract_funding(signal_text)
    countries = extract_countries(signal_text)
    remote = True if jsonld.get("remote") or REMOTE_RE.search(signal_text) else None
    hybrid = True if HYBRID_RE.search(signal_text) else None
    onsite = True if ONSITE_RE.search(signal_text) else None

    requirements = extract_bullets(
        soup, ("requirement", "eligib", "who can apply", "criteria", "qualification")
    )
    benefits = extract_bullets(soup, ("benefit", "what you get", "award", "perks", "offer"))

    eligibility_text = None
    for heading in soup.find_all(["h2", "h3", "h4"]):
        if "eligib" in heading.get_text(" ").lower():
            node = heading.find_next(["p", "ul"])
            if node:
                eligibility_text = truncate(strip_html(node.get_text(" ")), 700)
            break

    result = {
        "title": title,
        "organization": jsonld.get("organization") or meta.get("organization"),
        "description": description,
        "shortDescription": truncate(description, 200),
        "category": guess_category(signal_text, category_hint),
        "canonical": meta.get("canonical"),
        "applicationUrl": extract_application_url(soup, url),
        "deadline": deadline,
        "deadlineText": deadline_text,
        "applicationOpenDate": parse_date(jsonld.get("applicationOpenRaw"))
        if jsonld.get("applicationOpenRaw")
        else None,
        "countriesEligible": countries,
        "locations": jsonld.get("locations") or [],
        "remote": remote,
        "hybrid": hybrid,
        "onsite": onsite,
        "educationLevels": extract_education_levels(signal_text),
        "fieldsOfStudy": extract_fields(signal_text),
        "requiredSkills": extract_skills(signal_text[:6000]),
        "fundingType": funding_type,
        "fundingAmount": funding_amount,
        "currency": currency,
        "requirements": requirements,
        "benefits": benefits,
        "eligibilityText": eligibility_text,
        "closedMarker": has_closed_marker(text),
        "text": text,
        "usedJsonLd": bool(jsonld),
    }

    filled = sum(
        1
        for key in (
            "title",
            "organization",
            "description",
            "deadline",
            "countriesEligible",
            "requiredSkills",
            "fundingType",
            "requirements",
        )
        if result.get(key)
    )
    result["completeness"] = filled / 8
    result["concreteScore"] = concrete_opportunity_score(result)
    result["isLikelyOpportunity"] = is_likely_concrete_opportunity(result)
    del raw_soup
    return result

"""HTTP fetching with polite defaults, robots.txt awareness and optional Crawl4AI.

Crawl4AI / Playwright are imported lazily and only used when plain HTTP is
insufficient, so normal API startup never initialises a browser.

import asyncio

import urllib.robotparser as robotparser
from dataclasses import dataclass
from urllib.parse import urlparse

import httpx

from app.config import settings
from app.utils.urls import is_public_http_url

logger = logging.getLogger("orbit.scraper.fetch")

_robots_cache: dict[str, robotparser.RobotFileParser | None] = {}
_domain_locks: dict[str, asyncio.Lock] = {}


@dataclass
class FetchResult:
    url: str
    status: int
    html: str | None
    error: str | None = None
    method: str = "httpx"

    @property
    def ok(self) -> bool:
        return self.status == 200 and bool(self.html)

    @property
    def gone(self) -> bool:
        return self.status in (404, 410)


async def _robots_allowed(url: str) -> bool:
    parsed = urlparse(url)
    base = f"{parsed.scheme}://{parsed.netloc}"
    if base not in _robots_cache:
        parser: robotparser.RobotFileParser | None = robotparser.RobotFileParser()
        parser.set_url(f"{base}/robots.txt")
        try:
            async with httpx.AsyncClient(timeout=8, follow_redirects=True) as client:
                resp = await client.get(
                    f"{base}/robots.txt", headers={"User-Agent": settings.scraper_user_agent}
                )
            if resp.status_code == 200 and len(resp.text) < 500_000:
                parser.parse(resp.text.splitlines())
            else:
                parser = None
        except httpx.HTTPError:
            parser = None
        _robots_cache[base] = parser
    parser = _robots_cache[base]
    if parser is None:
        return True
    try:
        return parser.can_fetch(settings.scraper_user_agent, url)
    except Exception:
        return True


def _lock_for(url: str) -> asyncio.Lock:
    domain = urlparse(url).netloc
    if domain not in _domain_locks:
        _domain_locks[domain] = asyncio.Lock()
    return _domain_locks[domain]


async def fetch(url: str, crawl_delay: float = 1.0, respect_robots: bool = True) -> FetchResult:
    if not is_public_http_url(url):
        return FetchResult(url=url, status=0, html=None, error="blocked or non-public URL")
    if respect_robots and not await _robots_allowed(url):
        return FetchResult(url=url, status=0, html=None, error="disallowed by robots.txt")

    headers = {
        "User-Agent": settings.scraper_user_agent,
        "Accept": "text/html,application/xhtml+xml,application/xml;q=0.9,*/*;q=0.8",
        "Accept-Language": "en-US,en;q=0.9",
    }
    async with _lock_for(url):
        for attempt in range(2):
            try:
                async with httpx.AsyncClient(
                    timeout=settings.scraper_timeout, follow_redirects=True, headers=headers
                ) as client:
                    resp = await client.get(url)
                await asyncio.sleep(crawl_delay)
                content_type = resp.headers.get("content-type", "")
                if resp.status_code == 200 and (
                    "html" in content_type or "xml" in content_type or not content_type
                ):
                    return FetchResult(url=str(resp.url), status=200, html=resp.text)
                return FetchResult(
                    url=str(resp.url),
                    status=resp.status_code,
                    html=None,
                    error=f"unexpected response ({resp.status_code}, {content_type})",
                )
            except httpx.HTTPError as exc:
                if attempt == 1:
                    return FetchResult(url=url, status=0, html=None, error=str(exc)[:200])
                await asyncio.sleep(1.5)
    return FetchResult(url=url, status=0, html=None, error="unreachable")


async def fetch_rendered(url: str) -> FetchResult:
    """Render with Crawl4AI when plain HTTP yields no usable content.

    Crawl4AI is an optional dependency; if unavailable we degrade gracefully.
    """
    if not is_public_http_url(url):
        return FetchResult(url=url, status=0, html=None, error="blocked URL", method="crawl4ai")
    try:
        from crawl4ai import AsyncWebCrawler  # type: ignore
    except Exception:
        return FetchResult(
            url=url, status=0, html=None, error="crawl4ai not installed", method="crawl4ai"
        )
    try:
        async with AsyncWebCrawler(verbose=False) as crawler:
            result = await crawler.arun(url=url, bypass_cache=True)
        html = getattr(result, "html", None) or getattr(result, "cleaned_html", None)
        if html:
            return FetchResult(url=url, status=200, html=html, method="crawl4ai")
        return FetchResult(
            url=url, status=0, html=None, error="empty render", method="crawl4ai"
        )
    except Exception as exc:  # pragma: no cover - browser environment dependent
        return FetchResult(url=url, status=0, html=None, error=str(exc)[:200], method="crawl4ai")

"""Merge deterministic + AI extraction into a validated Opportunity document."""

from datetime import datetime, timezone

from app.models.opportunity import CATEGORIES, Opportunity
from app.utils.dates import days_remaining, parse_date
from app.utils.text import content_hash, fingerprint, sanitize_display, slugify, truncate
from app.utils.urls import canonicalize_url, domain_of

MIN_TITLE_LEN = 10


def _clean_list(values, limit: int = 20) -> list[str]:
    out, seen = [], set()
    for value in values or []:
        if not isinstance(value, str):
            continue
        value = sanitize_display(value)
        if not value or len(value) > 300:
            continue
        key = value.lower()
        if key not in seen:
            seen.add(key)
            out.append(value)
        if len(out) >= limit:
            break
    return out


def compute_status(deadline: datetime | None, closed: bool, verification: str) -> str:
    if closed:
        return "closed"
    days = days_remaining(deadline)
    if days is not None and days < 0:
        return "expired"
    if verification == "unverified":
        return "unverified"
    if days is not None and days <= 7:
        return "closing_soon"
    return "active"


def build_opportunity(
    url: str,
    deterministic: dict,
    ai: dict | None,
    source_id: str | None,
    source_type: str,
) -> Opportunity | None:
    """Combine extraction outputs. AI never overrides deterministic facts."""
    ai = ai or {}

    title = deterministic.get("title") or ai.get("title")
    if not title or len(title.strip()) < MIN_TITLE_LEN:
        return None

    canonical_raw = deterministic.get("canonical") or url
    canonical = canonicalize_url(canonical_raw) or canonicalize_url(url)
    if not canonical:
        return None

    description = sanitize_display(deterministic.get("description") or ai.get("description"))
    category = deterministic.get("category") or ai.get("category") or "other"
    if category not in CATEGORIES:
        category = "other"

    deadline = deterministic.get("deadline")
    deadline_text = deterministic.get("deadlineText")
    if not deadline and ai.get("deadline"):
        deadline = parse_date(str(ai["deadline"]))
        deadline_text = str(ai["deadline"]) if deadline else None

    countries = _clean_list(deterministic.get("countriesEligible") or ai.get("countriesEligible"))
    education = _clean_list(deterministic.get("educationLevels") or ai.get("educationLevels"), 10)
    fields = _clean_list(deterministic.get("fieldsOfStudy") or ai.get("fieldsOfStudy"), 10)
    skills = _clean_list(deterministic.get("requiredSkills") or ai.get("requiredSkills"), 20)
    requirements = _clean_list(deterministic.get("requirements") or ai.get("requirements"))
    benefits = _clean_list(deterministic.get("benefits") or ai.get("benefits"))

    funding_type = deterministic.get("fundingType") or ai.get("fundingType")
    funding_amount = deterministic.get("fundingAmount")
    if funding_amount is None and isinstance(ai.get("fundingAmount"), (int, float)):
        funding_amount = float(ai["fundingAmount"])
    currency = deterministic.get("currency") or ai.get("currency")

    remote = deterministic.get("remote")
    if remote is None and isinstance(ai.get("remote"), bool):
        remote = ai["remote"]

    ai_confidence = ai.get("confidence") if isinstance(ai.get("confidence"), (int, float)) else None
    completeness = deterministic.get("completeness", 0)

    is_primary = source_type in ("rss", "sitemap", "listing", "manual", "seed")
    if is_primary and (deterministic.get("usedJsonLd") or completeness >= 0.5):
        verification = "verified"
    elif completeness >= 0.375 or (ai_confidence or 0) >= 0.7:
        verification = "likely_verified"
    else:
        verification = "unverified"

    now = datetime.now(timezone.utc)
    text_for_hash = (deterministic.get("text") or "")[:20000]
    chash = content_hash(title, description, text_for_hash)

    application_url = deterministic.get("applicationUrl") or (ai.get("applicationUrl") if isinstance(ai.get("applicationUrl"), str) else None)
    if application_url:
        application_url = canonicalize_url(application_url) or None

    organization = sanitize_display(deterministic.get("organization") or ai.get("organization"))
    if organization:
        organization = organization[:140]

    return Opportunity(
        title=sanitize_display(title)[:220],
        organization=organization or domain_of(canonical),
        slug=slugify(title),
        description=truncate(description, 4000),
        shortDescription=truncate(description, 200),
        category=category,
        sourceUrl=url,
        applicationUrl=application_url,
        canonicalUrl=canonical,
        sourceDomain=domain_of(canonical),
        countriesEligible=countries,
        locations=_clean_list(deterministic.get("locations"), 8),
        remote=remote,
        hybrid=deterministic.get("hybrid"),
        onsite=deterministic.get("onsite"),
        educationLevels=education,
        fieldsOfStudy=fields,
        requiredSkills=skills,
        preferredSkills=[],
        experienceLevels=[],
        fundingType=funding_type,
        fundingAmount=funding_amount,
        currency=currency,
        deadline=deadline,
        deadlineText=truncate(deadline_text, 120),
        applicationOpenDate=deterministic.get("applicationOpenDate"),
        eligibilityText=truncate(deterministic.get("eligibilityText"), 900),
        requirements=requirements,
        benefits=benefits,
        verified=verification == "verified",
        verificationStatus=verification,
        sourceType=source_type,
        extractionMethod="jsonld+html" + ("+ai" if ai else ""),
        aiConfidence=float(ai_confidence) if ai_confidence is not None else None,
        status=compute_status(deadline, bool(deterministic.get("closedMarker")), verification),
        scrapedAt=now,
        lastSeenAt=now,
        lastCheckedAt=now,
        lastChangedAt=now,
        contentHash=chash,
        fingerprint=fingerprint(
            organization or domain_of(canonical), title, deadline.isoformat() if deadline else None
        ),
        sourceId=source_id,
        createdAt=now,
        updatedAt=now,
    )

from __future__ import annotations

import logging

async def _acquire_lock(name: str = "opportunity-sync", ttl_minutes: int = 45) -> bool:
    """Atomically claim the singleton ingestion lock.

    The unique `name` index makes concurrent upserts safe: if another worker already
    owns an unexpired lock, its insert attempt collides and we return False.
    """
    db = get_db()
    now = datetime.now(timezone.utc)
    expires = now + timedelta(minutes=ttl_minutes)
    try:
        result = await db.locks.update_one(
            {
                "name": name,
                "$or": [
                    {"expiresAt": {"$lte": now}},
                    {"expiresAt": {"$exists": False}},
                ],
            },
            {"$set": {"name": name, "acquiredAt": now, "expiresAt": expires}},
            upsert=True,
        )
        return bool(result.matched_count or result.upserted_id)
    except DuplicateKeyError:
        return False


async def _release_lock(name: str = "opportunity-sync") -> None:
    await get_db().locks.delete_one({"name": name})


async def create_run(trigger: str = "manual") -> str:
    run = ScrapeRun(trigger=trigger)
    doc = run.to_mongo(exclude_none=True)
    result = await get_db().scrape_runs.insert_one(doc)
    return str(result.inserted_id)


async def get_run(run_id: str) -> dict | None:
    try:
        oid = ObjectId(run_id)
    except Exception:

    return await get_db().scrape_runs.find_one({"_id": oid})


async def _finish_run(run_id: str, metrics: dict, status: str, errors: list[str]) -> None:
    try:
        oid = ObjectId(run_id)
    except Exception:

                "status": status,
                "errors": errors[-25:],
                "finishedAt": datetime.now(timezone.utc),
            }
        },
    )


async def _mark_fetch_failure(existing: dict | None, gone: bool) -> None:
    if not existing:
        return
    db = get_db()
    failures = int(existing.get("consecutiveFetchFailures") or 0) + 1
    update = {
        "consecutiveFetchFailures": failures,
        "lastCheckedAt": datetime.now(timezone.utc),
    }
    if gone and failures >= settings.consecutive_gone_threshold:
        update["status"] = "closed"
    await db.opportunities.update_one({"_id": existing["_id"]}, {"$set": update})


async def expire_old_opportunities() -> int:
    """Remove dead master records while preserving independent saved snapshots."""
    db = get_db()
    now = datetime.now(timezone.utc)

    # Normalize statuses first.
    result = await db.opportunities.update_many(
        {
            "deadline": {"$lt": now},
            "status": {"$in": ["active", "closing_soon", "unverified"]},
        },
        {"$set": {"status": "expired", "updatedAt": now}},
    )
    expired_count = int(result.modified_count)

    if not settings.delete_expired_master:
        return expired_count

    cursor = db.opportunities.find(
        {"status": {"$in": ["expired", "closed"]}},
        {"_id": 1},
    )
    ids_to_delete = []
    async for doc in cursor:
        opp_id = str(doc["_id"])
        await db.saved_opportunities.update_many(
            {"originalOpportunityId": opp_id},
            {"$set": {"masterDeleted": True, "updatedAt": now}},
        )
        ids_to_delete.append(doc["_id"])

    if ids_to_delete:
        await db.opportunities.delete_many({"_id": {"$in": ids_to_delete}})
    return expired_count


async def ingest_candidate(
    candidate: dict,
    source: dict | None,
    ai_budget_remaining: int,
) -> dict:
    db = get_db()
    url = canonicalize_url(candidate.get("url", ""))
    if not url:
        return {"state": "failed", "aiCalls": 0, "error": "invalid candidate URL"}

    existing = await db.opportunities.find_one({"canonicalUrl": url})
    result = await fetch(
        url,
        crawl_delay=float((source or {}).get("crawlDelay") or settings.scraper_default_delay),
    )
    if not result.ok:
        await _mark_fetch_failure(existing, result.gone)
        return {
            "state": "failed",
            "aiCalls": 0,
            "error": result.error or f"fetch failed ({result.status})",
        }

    deterministic = deterministic_extract(
        result.url,
        result.html or "",
        category_hint=(source or {}).get("category"),
    )

    # JS shell / very weak parse: optional rendered fallback.
    if deterministic.get("completeness", 0) < 0.25 and len(deterministic.get("text") or "") < 500:
        rendered = await fetch_rendered(result.url)
        if rendered.ok and rendered.html:
            deterministic = deterministic_extract(
                rendered.url,
                rendered.html,
                category_hint=(source or {}).get("category"),
            )

    # Cheap unchanged check before any AI call.
    preliminary = build_opportunity(
        result.url,
        deterministic,
        None,
        str((source or {}).get("_id")) if (source or {}).get("_id") else None,
        candidate.get("sourceType") or (source or {}).get("discoveryType") or "listing",
    )
    if preliminary and existing and existing.get("contentHash") == preliminary.contentHash:
        await db.opportunities.update_one(
            {"_id": existing["_id"]},
            {
                "$set": {
                    "lastSeenAt": datetime.now(timezone.utc),
                    "lastCheckedAt": datetime.now(timezone.utc),
                    "consecutiveFetchFailures": 0,
                }
            },
        )
        return {"state": "unchanged", "aiCalls": 0}

    ai_data = None
    ai_calls = 0
    ambiguous_page = not bool(deterministic.get("isLikelyOpportunity"))

    # Precision gate: generic listing/index pages should not become opportunity cards.
    # If Groq is configured, ambiguous pages get one cheap classifier call. Without
    # Groq we accept only deterministic pages with strong concrete-opportunity signals.
    if ambiguous_page:
        if not groq_client.enabled or ai_budget_remaining <= 0:
            return {"state": "rejected", "aiCalls": 0}
        before = groq_client.calls_made
        classification = await classify_page(
            deterministic.get("title") or candidate.get("title") or "",
            deterministic.get("text") or "",
        )
        ai_calls += max(0, groq_client.calls_made - before)
        if not isinstance(classification, dict) or not classification.get("isOpportunity"):
            return {"state": "rejected", "aiCalls": ai_calls}

    needs_extraction_ai = (
        groq_client.enabled
        and ai_budget_remaining > ai_calls
        and deterministic.get("completeness", 0) < settings.min_ai_extraction_completeness
    )
    if needs_extraction_ai:
        before = groq_client.calls_made
        ai_data = await extract_opportunity(
            result.url,
            deterministic.get("title") or candidate.get("title") or "",
            deterministic.get("text") or "",
        )
        ai_calls += max(0, groq_client.calls_made - before)
        if isinstance(ai_data, dict) and ai_data.get("isOpportunity") is False:
            return {"state": "rejected", "aiCalls": ai_calls}

    opportunity = build_opportunity(
        result.url,
        deterministic,
        ai_data,
        str((source or {}).get("_id")) if (source or {}).get("_id") else None,
        candidate.get("sourceType") or (source or {}).get("discoveryType") or "listing",
    )
    if not opportunity:
        return {"state": "rejected", "aiCalls": ai_calls}

    found = await find_existing(db, opportunity)
    now = datetime.now(timezone.utc)
    if found:
        if is_duplicate_of(found, opportunity):
            await db.opportunities.update_one(
                {"_id": found["_id"]},
                {"$set": {"lastSeenAt": now, "lastCheckedAt": now}},
            )
            return {"state": "duplicate", "aiCalls": ai_calls}

        new_doc = opportunity.to_mongo(exclude_none=True)
        new_doc.pop("_id", None)
        new_doc["createdAt"] = found.get("createdAt", new_doc.get("createdAt", now))
        new_doc["lastChangedAt"] = now
        new_doc["consecutiveFetchFailures"] = 0
        await db.opportunities.update_one({"_id": found["_id"]}, {"$set": new_doc})
        return {"state": "updated", "aiCalls": ai_calls, "id": str(found["_id"])}

    doc = opportunity.to_mongo(exclude_none=True)
    doc["consecutiveFetchFailures"] = 0
    inserted = await db.opportunities.insert_one(doc)
    return {"state": "new", "aiCalls": ai_calls, "id": str(inserted.inserted_id)}


async def run_ingestion(
    trigger: str = "manual",
    query: str | None = None,
    max_candidates: int | None = None,
    run_id: str | None = None,
) -> dict:
    db = get_db()
    run_id = run_id or await create_run(trigger)
    max_candidates = min(
        max_candidates or settings.max_candidates_per_run,
        200,
    )

    metrics = {
        "sourcesAttempted": 0,
        "sourcesSucceeded": 0,
        "urlsDiscovered": 0,
        "urlsFetched": 0,
        "newCount": 0,
        "updatedCount": 0,
        "duplicateCount": 0,
        "expiredCount": 0,
        "failedCount": 0,
        "aiCalls": 0,
    }
    errors: list[str] = []

    if not await _acquire_lock():
        errors.append("Another ingestion run is already active")
        await _finish_run(run_id, metrics, "failed", errors)
        doc = await get_run(run_id)
        return serialize(doc or {"id": run_id, **metrics, "status": "failed", "errors": errors})

    try:
        candidates: list[tuple[dict, dict | None]] = []

        if query and query.strip():
            discovered = await discover_query(query.strip(), max_results=max_candidates)
            candidates.extend((item, None) for item in discovered)

        # Registry crawling remains the primary discovery path, even when SearXNG is absent.
        if len(candidates) < max_candidates:
            sources = await db.sources.find({"enabled": True}).sort("priority", -1).to_list(100)
            for source in sources:
                if len(candidates) >= max_candidates:
                    break
                metrics["sourcesAttempted"] += 1
                now = datetime.now(timezone.utc)
                await db.sources.update_one({"_id": source["_id"]}, {"$set": {"lastRunAt": now}})
                try:
                    items = await discover_source(
                        source,
                        max_results=min(
                            settings.max_urls_per_source,
                            max_candidates - len(candidates),
                        ),
                    )
                    metrics["sourcesSucceeded"] += 1
                    await db.sources.update_one(
                        {"_id": source["_id"]},
                        {
                            "$set": {
                                "lastSuccessAt": now,
                                "lastError": None,
                                "consecutiveFailures": 0,
                            }
                        },
                    )
                    candidates.extend((item, source) for item in items)
                except Exception as exc:
                    message = f"{source.get('name', 'source')}: {str(exc)[:180]}"
                    errors.append(message)
                    await db.sources.update_one(
                        {"_id": source["_id"]},
                        {
                            "$set": {"lastError": str(exc)[:400]},
                            "$inc": {"consecutiveFailures": 1},
                        },
                    )

        # Canonical URL dedupe before fetching.
        unique: list[tuple[dict, dict | None]] = []
        seen = set()
        for candidate, source in candidates:
            url = canonicalize_url(candidate.get("url", ""))
            if not url or url in seen:
                continue
            seen.add(url)
            candidate = {**candidate, "url": url}
            unique.append((candidate, source))
            if len(unique) >= max_candidates:
                break

        metrics["urlsDiscovered"] = len(unique)

        for candidate, source in unique:
            ai_remaining = max(0, settings.max_ai_calls_per_sync - metrics["aiCalls"])
            outcome = await ingest_candidate(candidate, source, ai_remaining)
            state = outcome.get("state")
            metrics["aiCalls"] += int(outcome.get("aiCalls") or 0)
            if state not in {"failed"}:
                metrics["urlsFetched"] += 1
            if state == "new":
                metrics["newCount"] += 1
            elif state == "updated":
                metrics["updatedCount"] += 1
            elif state == "duplicate":
                metrics["duplicateCount"] += 1
            elif state == "failed":
                metrics["failedCount"] += 1
                if outcome.get("error"):
                    errors.append(f"{candidate.get('url')}: {outcome['error'][:180]}")

        metrics["expiredCount"] = await expire_old_opportunities()
        if metrics["failedCount"] and (metrics["newCount"] or metrics["updatedCount"] or metrics["urlsFetched"]):
            status = "partial"
        elif metrics["failedCount"] and not metrics["urlsFetched"]:
            status = "failed"
        else:
            status = "success"

        await _finish_run(run_id, metrics, status, errors)
    except Exception as exc:
        logger.exception("Ingestion run failed")
        errors.append(str(exc)[:500])
        await _finish_run(run_id, metrics, "failed", errors)
    finally:
        await _release_lock()

    doc = await get_run(run_id)
    return serialize(doc or {"id": run_id, **metrics, "status": "failed", "errors": errors})

import re
from datetime import datetime, timezone

from dateutil import parser as dateutil_parser

DEADLINE_PATTERNS = [
    r"deadline[:\s]*(?:is\s*)?([A-Z][a-z]+\s+\d{1,2},?\s+\d{4}(?:\s+\d{1,2}:\d{2}\s*(?:am|pm)?)?)",
    r"deadline[:\s]*(\d{1,2}\s+[A-Z][a-z]+\s+\d{4})",
    r"deadline[:\s]*(\d{4}-\d{2}-\d{2}(?:[T\s][0-9:+\-Z\.]+)?)",
    r"apply(?:\s+)?(?:by|before)[:\s]*([A-Z][a-z]+\s+\d{1,2},?\s+\d{4})",
    r"closes?\s+on[:\s]*([A-Z][a-z]+\s+\d{1,2},?\s+\d{4})",
    r"applications?\s+close[sd]?[:\s]*(?:on\s*)?([A-Z][a-z]+\s+\d{1,2},?\s+\d{4})",
    r"last date[:\s]*(?:to apply\s*)?([A-Z][a-z]+\s+\d{1,2},?\s+\d{4})",
]

CLOSED_MARKERS = (
    "applications are closed",
    "applications closed",
    "application closed",
    "deadline has passed",
    "deadline passed",
    "no longer accepting applications",
    "this opportunity has expired",
    "submissions are closed",
)


def parse_date(value: str | None) -> datetime | None:
    """Parse only explicit dates into timezone-aware UTC datetimes.

    A four-digit year is required so strings such as "May 3" are not silently
    guessed into the current/future year.
    """
    if not value or not isinstance(value, str):
        return None
    value = value.strip()
    if len(value) < 4 or len(value) > 120 or not re.search(r"\b\d{4}\b", value):
        return None
    try:
        normalized = value.replace("Z", "+00:00")
        try:
            dt = datetime.fromisoformat(normalized)
        except ValueError:
            dt = dateutil_parser.parse(value, fuzzy=False)
    except (ValueError, TypeError, OverflowError):
        return None
    if dt.tzinfo is None:
        dt = dt.replace(tzinfo=timezone.utc)
    return dt.astimezone(timezone.utc)


def extract_deadline(text: str | None) -> tuple[datetime | None, str | None]:
    if not text:
        return None, None
    for pattern in DEADLINE_PATTERNS:
        match = re.search(pattern, text, re.IGNORECASE)
        if match:
            raw = match.group(1)
            parsed = parse_date(raw)
            if parsed:
                return parsed, raw
    return None, None


def has_closed_marker(text: str | None) -> bool:
    if not text:
        return False
    lowered = text.lower()
    return any(marker in lowered for marker in CLOSED_MARKERS)


def days_remaining(deadline: datetime | None) -> int | None:
    if not deadline:
        return None
    if deadline.tzinfo is None:
        deadline = deadline.replace(tzinfo=timezone.utc)
    delta = deadline - datetime.now(timezone.utc)
    return int(delta.total_seconds() // 86400)

import logging
import sys


def setup_logging(level: int = logging.INFO) -> None:
    handler = logging.StreamHandler(sys.stdout)
    handler.setFormatter(
        logging.Formatter("%(asctime)s | %(levelname)-7s | %(name)s | %(message)s")
    )
    root = logging.getLogger()
    root.handlers = [handler]
    root.setLevel(level)
    logging.getLogger("httpx").setLevel(logging.WARNING)

from __future__ import annotations

from datetime import datetime
from typing import Any

from bson import ObjectId
from bson.errors import InvalidId


def object_id(value: str) -> ObjectId | None:
    try:
        return ObjectId(value)
    except (InvalidId, TypeError):
        return None


def serialize(value: Any) -> Any:
    if isinstance(value, ObjectId):
        return str(value)
    if isinstance(value, datetime):
        return value.isoformat()
    if isinstance(value, dict):
        out = {}
        for key, item in value.items():
            if key == "_id":
                out["id"] = serialize(item)
            else:
                out[key] = serialize(item)
        return out
    if isinstance(value, list):
        return [serialize(v) for v in value]
    if isinstance(value, tuple):
        return [serialize(v) for v in value]
    return value

import hashlib
import re
import unicodedata

TAG_RE = re.compile(r"<[^>]+>")
WS_RE = re.compile(r"\s+")


def strip_html(value: str | None) -> str:
    if not value:
        return ""
    return WS_RE.sub(" ", TAG_RE.sub(" ", value)).strip()


def normalize_text(value: str | None) -> str:
    if not value:
        return ""
    value = unicodedata.normalize("NFKD", value).encode("ascii", "ignore").decode()
    value = re.sub(r"[^a-z0-9\s]", " ", value.lower())
    return WS_RE.sub(" ", value).strip()


def slugify(value: str, max_len: int = 80) -> str:
    normalized = normalize_text(value).replace(" ", "-")
    return normalized[:max_len].strip("-") or "opportunity"


def content_hash(*parts: str | None) -> str:
    joined = "\u0001".join(normalize_text(p) for p in parts if p)
    return hashlib.sha256(joined.encode()).hexdigest()


def fingerprint(organization: str | None, title: str | None, deadline_iso: str | None) -> str:
    return hashlib.sha1(
        "|".join(
            [normalize_text(organization), normalize_text(title), (deadline_iso or "")[:10]]
        ).encode()
    ).hexdigest()


def truncate(value: str | None, limit: int = 240) -> str | None:
    if not value:
        return None
    value = value.strip()
    if len(value) <= limit:
        return value
    return value[: limit - 1].rsplit(" ", 1)[0] + "\u2026"


def sanitize_display(value: str | None) -> str | None:
    """Remove markup/script content from text that will be rendered."""
    if not value:
        return None
    cleaned = re.sub(r"(?is)<(script|style).*?>.*?</\1>", " ", value)
    return strip_html(cleaned) or None

import ipaddress
import socket
from urllib.parse import parse_qsl, urlencode, urlparse, urlunparse

TRACKING_PREFIXES = ("utm_",)
TRACKING_KEYS = {
    "fbclid",
    "gclid",
    "gclsrc",
    "dclid",
    "msclkid",
    "mc_cid",
    "mc_eid",
    "igshid",
    "ref",
    "ref_src",
    "source",
    "_hsenc",
    "_hsmi",
    "yclid",
    "wickedid",
}

BLOCKED_EXTENSIONS = (
    ".pdf",
    ".jpg",
    ".jpeg",
    ".png",
    ".gif",
    ".svg",
    ".zip",
    ".mp4",
    ".mp3",
    ".css",
    ".js",
)


def canonicalize_url(url: str) -> str:
    """Normalize a URL: strip tracking params, fragments, trailing slash, lowercase host."""
    if not url:
        return ""
    url = url.strip()
    parsed = urlparse(url)
    # Only canonicalize absolute URLs. Relative canonical tags are resolved
    # against the fetched page before reaching this helper.
    if not parsed.netloc:
        return ""
    scheme = (parsed.scheme or "https").lower()
    if scheme not in ("http", "https"):
        return ""
    netloc = parsed.netloc.lower()
    if netloc.startswith("www."):
        netloc = netloc[4:]
    if netloc.endswith(":80") or netloc.endswith(":443"):
        netloc = netloc.rsplit(":", 1)[0]

    query_pairs = [
        (k, v)
        for k, v in parse_qsl(parsed.query, keep_blank_values=False)
        if k.lower() not in TRACKING_KEYS
        and not any(k.lower().startswith(p) for p in TRACKING_PREFIXES)
    ]
    query = urlencode(sorted(query_pairs))

    path = parsed.path or "/"
    if len(path) > 1 and path.endswith("/"):
        path = path.rstrip("/")

    return urlunparse((scheme, netloc, path, "", query, ""))


def domain_of(url: str) -> str:
    netloc = urlparse(url).netloc.lower()
    return netloc[4:] if netloc.startswith("www.") else netloc


def is_public_http_url(url: str) -> bool:
    """SSRF guard: only public http(s) hosts, no private/loopback addresses."""
    try:
        parsed = urlparse(url)
    except ValueError:
        return False
    if parsed.scheme not in ("http", "https") or not parsed.hostname:
        return False
    host = parsed.hostname
    if host in ("localhost",) or host.endswith(".local") or host.endswith(".internal"):
        return False
    try:
        infos = socket.getaddrinfo(host, None)
    except socket.gaierror:
        return False
    for info in infos:
        try:
            ip = ipaddress.ip_address(info[4][0])
        except ValueError:
            return False
        if ip.is_private or ip.is_loopback or ip.is_link_local or ip.is_reserved:
            return False
    return True


def looks_like_content_url(url: str) -> bool:
    lowered = url.lower()
    if any(lowered.endswith(ext) for ext in BLOCKED_EXTENSIONS):
        return False
    path = urlparse(lowered).path
    return len(path) > 8

from datetime import datetime, timezone

from app.services.scrapper.extract import deterministic_extract

def test_parse_date_requires_explicit_year():
    assert parse_date("September 14, 2026") is not None
    assert parse_date("September 14") is None


def test_deadline_extraction():
    dt, raw = extract_deadline("Application deadline: September 14, 2026")
    assert dt == datetime(2026, 9, 14, tzinfo=timezone.utc)
    assert raw == "September 14, 2026"


def test_deterministic_extraction_finds_apply_and_signals():
    html = """
    <html><head><title>AI Internship 2026</title>
    <meta name="description" content="Paid fully remote AI internship"></head>
    <body><h1>AI Internship 2026</h1>
    <p>Deadline: September 14, 2026</p>
    <a href="/apply">Apply now</a></body></html>
    """
    out = deterministic_extract("https://example.com/internship", html)
    assert out["category"] == "internship"
    assert out["applicationUrl"] == "https://example.com/apply"
    assert out["remote"] is True
    assert out["fundingType"] == "paid"
    assert out["deadline"].date().isoformat() == "2026-09-14"


def test_match_engine_profile_fit():
    result = score_opportunity(
        {
            "requiredSkills": ["Python", "React"],
            "countriesEligible": ["Global"],
            "category": "internship",
            "remote": True,
            "fundingType": "stipend",
        },
        {
            "skills": ["Python"],
            "country": "Pakistan",
            "preferredCategories": ["internship"],
            "locationPreference": ["remote"],
            "fundingPreference": "funded_only",
        },
    )
    assert result["matchScore"] >= 70
    assert result["eligibilityStatus"] == "eligible"
    assert "React" in result["missingSkills"]

    out = deterministic_query_filters(
        "Find fully funded remote AI internships closing within 60 days"
    )
    assert "internship" in out["categories"]
    assert out["remote"] is True
    assert out["fundingRequired"] is True
